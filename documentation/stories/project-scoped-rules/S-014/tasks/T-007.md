# S-014-T7: Fix --body= Escape Handling

**Priority:** P0 | **Status:** pending | **Blocked By:** --

## What
Add `unescapeBody()` function to `lib/body.mjs` that decodes `\n`, `\t`, `\r`, and `\\` in `--body=` values using a single-pass regex. Create `test/body.test.mjs` with 8 test cases.

## Why
Currently `readBody()` returns the raw `--body=` value without unescaping, so `brief log create --body="line1\nline2"` stores a literal backslash-n instead of a newline. This makes multi-line bodies impossible without stdin piping.

## Context
Current readBody function at lib/body.mjs:

```javascript
export async function readBody(rawArgs) {
  for (const arg of rawArgs) {
    if (arg.startsWith("--body=")) {
      return arg.slice("--body=".length);
    }
  }

  if (!process.stdin.isTTY) {
    const chunks = [];
    for await (const chunk of process.stdin) {
      chunks.push(chunk);
    }
    const body = Buffer.concat(chunks).toString("utf8").trim();
    if (body) return body;
  }

  return null;
}
```

TRD design decision: single-pass regex `/\\([ntr\\])/g` with lookup map. Sequential `.replace()` has ordering bugs — `\\n` would be incorrectly decoded if `\\` is replaced before `\n`. The regex consumes each escape as one match, avoiding the issue.

**Critical: readBody is async** (returns Promise because of the stdin `for await`). All test assertions must use `await`. The eng review (Claude subagent finding #4) caught that the TRD's test examples omit await — tests comparing Promise to string silently pass as falsy.

## How

**Step 1 -- Add unescapeBody function:**
- File: `lib/body.mjs`
- Add before the export:

```javascript
const ESCAPE_MAP = { n: "\n", t: "\t", r: "\r", "\\": "\\" };

function unescapeBody(str) {
  return str.replace(/\\([ntr\\])/g, (_, ch) => ESCAPE_MAP[ch] ?? `\\${ch}`);
}
```

**Step 2 -- Wire into readBody:**
- Change the `--body=` return from:
  ```javascript
  return arg.slice("--body=".length);
  ```
  to:
  ```javascript
  return unescapeBody(arg.slice("--body=".length));
  ```

**Step 3 -- Create test file:**
- File: `test/body.test.mjs`

```javascript
import { describe, it } from "node:test";
import assert from "node:assert/strict";
import { readBody } from "../lib/body.mjs";

describe("readBody --body= escape handling", () => {
  it("replaces \\n with newline", async () => {
    assert.equal(await readBody(["--body=a\\nb"]), "a\nb");
  });

  it("replaces \\t with tab", async () => {
    assert.equal(await readBody(["--body=a\\tb"]), "a\tb");
  });

  it("replaces \\r with carriage return", async () => {
    assert.equal(await readBody(["--body=a\\rb"]), "a\rb");
  });

  it("replaces \\\\ with single backslash", async () => {
    assert.equal(await readBody(["--body=a\\\\b"]), "a\\b");
  });

  it("preserves literal \\n when double-escaped", async () => {
    assert.equal(await readBody(["--body=a\\\\nb"]), "a\\nb");
  });

  it("handles no escapes", async () => {
    assert.equal(await readBody(["--body=plain text"]), "plain text");
  });

  it("handles empty body", async () => {
    assert.equal(await readBody(["--body="]), "");
  });

  it("handles multiple escapes", async () => {
    assert.equal(await readBody(["--body=a\\nb\\tc"]), "a\nb\tc");
  });
});
```
