# S-014-T4: Expand Manifest Detect Patterns

**Priority:** P1 | **Status:** pending | **Blocked By:** --

## What
Add missing detect patterns to `templates/rules/manifest.json`: `wrangler.toml`, `vercel.json` for the deployment rule, and `pyproject.toml:django|flask|fastapi` for backend-standards. Also add `package.json:next|nuxt|@remix-run/react` for frontend-standards.

## Why
The deployment rule's detect array currently has `["Dockerfile", "fly.toml", "wrangler.jsonc"]` but misses `wrangler.toml` (classic Cloudflare config) and `vercel.json`. backend-standards only detects Node.js frameworks, not Python ones. frontend-standards misses Next.js, Nuxt, and Remix. These gaps mean `brief init` doesn't install relevant rules for those projects.

Eng review (finding 1A) confirmed: check both wrangler.toml and wrangler.jsonc. Eng review (finding 7A) confirmed observability/analytics detection is a separate TODO (TODO-015), not in this PR.

## Context
The current manifest detect patterns and the matchesDetection code work together:
- `detect: ["*"]` → always install (matchesDetection returns true on wildcard)
- `detect: [".git"]` → install in any git repo
- `detect: ["package.json:express|hono"]` → matchesDetection splits on `:`, checks `detection.frameworks` for each name
- `detect: ["Dockerfile"]` → currently hits a `continue` at init.mjs:212 (will be replaced with existsSync in T-005)

The `file:framework` pattern is generic — matchesDetection's framework matching branch (init.mjs:216-224) ignores the file prefix and checks `detection.frameworks` only. So adding `pyproject.toml:django|flask|fastapi` works with ZERO code changes — `detectStack()` already populates `detection.frameworks` with django/flask/fastapi from pyproject.toml (detect.mjs:180-194).

## How

**Step 1 -- Update deployment detect array:**
- File: `templates/rules/manifest.json`
- Find the deployment entry (id: "deployment")
- Change detect from:
  ```json
  "detect": [".github/workflows", "Dockerfile", "fly.toml", "wrangler.jsonc"]
  ```
  to:
  ```json
  "detect": [".github/workflows", "Dockerfile", "fly.toml", "wrangler.toml", "wrangler.jsonc", "vercel.json"]
  ```

**Step 2 -- Update backend-standards detect array:**
- Find the backend-standards entry (id: "backend-standards")
- Change detect from:
  ```json
  "detect": ["package.json:express|fastify|hono|koa", "Cargo.toml", "go.mod"]
  ```
  to:
  ```json
  "detect": ["package.json:express|fastify|hono|koa", "pyproject.toml:django|flask|fastapi", "Cargo.toml", "go.mod"]
  ```

**Step 3 -- Update frontend-standards detect array:**
- Find the frontend-standards entry (id: "frontend-standards")
- Change detect from:
  ```json
  "detect": ["package.json:react|vue|svelte|solid"]
  ```
  to:
  ```json
  "detect": ["package.json:react|vue|svelte|solid|next|nuxt|@remix-run/react"]
  ```

**Step 4 -- Verify:**
```bash
node -e "
const m = JSON.parse(require('fs').readFileSync('templates/rules/manifest.json','utf8'));
const d = m.templates.find(t=>t.id==='deployment');
console.log('deployment detect:', d.detect);
const b = m.templates.find(t=>t.id==='backend-standards');
console.log('backend detect:', b.detect);
const f = m.templates.find(t=>t.id==='frontend-standards');
console.log('frontend detect:', f.detect);
"
node --test
```
