# S-014-T6: Add Grouped Display to printSummary

**Priority:** P1 | **Status:** pending | **Blocked By:** S-014-T5

## What
Modify `printSummary()` in `lib/init.mjs` to group rule output: universal rules (detect:["*"] or detect:[".git",".github"]) collapsed into one line, stack-specific rules listed individually.

## Why
Currently `printSummary` lists every rule individually, which gets noisy as the rule library grows (now 12 templates, 5-7 of which are universal). Collapsing universal rules into "Universal: N rules" keeps the output focused on what's project-specific.

## Context
Current printSummary code at lib/init.mjs:324-357:

```javascript
function printSummary(projectRoot, detection, relevantRules, harnessState) {
  // ... header, detection info, agents ...

  if (relevantRules.length) {
    console.log("");
    console.log("Rules to install (based on detected stack):");
    for (const rule of relevantRules) {
      console.log(`  + ${rule.file.padEnd(28)} (${rule.name.toLowerCase()})`);
    }
  }
  console.log("──────────────────────────────────────────────────");
}
```

Eng review decision (4A): classify by detect pattern:
- **Universal:** Any rule whose detect array contains `"*"` OR consists only of `.git`/`.github` entries
- **Stack-specific:** Everything else

The manifest is loaded inside `filterRelevantRules`, but `printSummary` receives the filtered `relevantRules` array which includes each template object with its `detect` field. So the grouping can be done by inspecting `rule.detect`.

## How

**Step 1 -- Add helper function:**
- File: `lib/init.mjs`
- Add near the top of the file (after the imports/constants) or just before printSummary:

```javascript
function isUniversalRule(rule) {
  return rule.detect.some(p => p === "*") ||
    rule.detect.every(p => p === ".git" || p === ".github");
}
```

**Step 2 -- Replace the rules display section in printSummary:**
Replace the `if (relevantRules.length)` block with:

```javascript
  if (relevantRules.length) {
    const universal = relevantRules.filter(isUniversalRule);
    const specific = relevantRules.filter(r => !isUniversalRule(r));

    console.log("");
    if (universal.length) {
      console.log(`Rules to install: Universal: ${universal.length} rules`);
    }
    if (specific.length) {
      console.log(universal.length ? "Stack-specific rules:" : "Rules to install (based on detected stack):");
      for (const rule of specific) {
        console.log(`  + ${rule.file.padEnd(28)} (${rule.name.toLowerCase()})`);
      }
    }
  }
```
