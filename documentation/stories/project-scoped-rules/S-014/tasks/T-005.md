# S-014-T5: Expand matchesDetection with projectRoot + Export for Testing

**Priority:** P0 | **Status:** pending | **Blocked By:** S-014-T4

## What
Thread `projectRoot` through `filterRelevantRules` → `matchesDetection` in `lib/init.mjs`. Replace the `continue` statement at line 212 with `existsSync(join(projectRoot, file))` checks. Export both functions for unit testing. Write 7 new test cases in `test/init.test.mjs`.

## Why
matchesDetection currently skips Dockerfile, fly.toml, and wrangler.jsonc with a `continue` statement (a deferral marker from S-012). With projectRoot available, these can be resolved via filesystem checks. Exporting the functions enables direct unit testing (eng review decision 2A).

## Context
Current code at lib/init.mjs:

```javascript
// line 62 — caller:
const relevantRules = filterRelevantRules(detection);

// line 186 — first function:
function filterRelevantRules(detection) {
  const manifestPath = join(RULES_TEMPLATES_DIR, "manifest.json");
  if (!existsSync(manifestPath)) return [];
  const manifest = JSON.parse(readFileSync(manifestPath, "utf8"));
  const relevant = [];
  for (const template of manifest.templates) {
    if (matchesDetection(template.detect, detection)) {
      relevant.push(template);
    }
  }
  return relevant;
}

// line 201 — second function:
function matchesDetection(detectPatterns, detection) {
  for (const pattern of detectPatterns) {
    if (pattern === "*") return true;
    if (pattern === ".git" || pattern === ".github") return true;
    const [file, frameworks] = pattern.split(":");
    if (!frameworks) {
      if (file === "Cargo.toml" && detection.runtime === "rust") return true;
      if (file === "go.mod" && detection.runtime === "go") return true;
      // line 212 — THE DEFERRAL:
      if (file === "Dockerfile" || file === "fly.toml" || file === "wrangler.jsonc") continue;
      if (file === ".github/workflows" && detection.hasCI) return true;
      continue;
    }
    const names = frameworks.split("|");
    for (const name of names) {
      if (detection.frameworks.includes(name)) return true;
      if (name.startsWith("@") && detection.frameworks.some(f => f.startsWith(name))) return true;
    }
  }
  return false;
}
```

The `continue` at line 212 is the exact target. After T-004 adds wrangler.toml and vercel.json to the manifest, those patterns will also hit this branch.

Testing pattern: Node.js built-in test runner (`node --test`), `describe`/`it` from `node:test`, `assert` from `node:assert/strict`. Temp fixtures with `mkdtempSync`. See `test/harness.test.mjs` for the project convention.

## How

**Step 1 -- Thread projectRoot through filterRelevantRules:**
- File: `lib/init.mjs`
- Change line 62 from:
  ```javascript

  ```

  ```javascript

  ```

- Change function signature at line 186 from:

  to:

- Change the matchesDetection call inside from:
  ```javascript

  ```
  to:
  ```javascript
  if (matchesDetection(template.detect, detection, projectRoot)) {
  ```

**Step 2 -- Add projectRoot to matchesDetection and replace continue:**
- Change function signature at line 201 from:
  ```javascript
  function matchesDetection(detectPatterns, detection) {
  ```
  to:
  ```javascript
  export function matchesDetection(detectPatterns, detection, projectRoot) {
  ```

- Replace line 212:
  ```javascript
  if (file === "Dockerfile" || file === "fly.toml" || file === "wrangler.jsonc") continue;
  ```
  with:
  ```javascript
  if (projectRoot && existsSync(join(projectRoot, file))) return true;
  ```

  The `projectRoot &&` guard ensures backward compatibility if called without projectRoot (though all callers will pass it). This single line handles ALL bare filename patterns generically — Dockerfile, fly.toml, wrangler.toml, wrangler.jsonc, vercel.json, and any future additions to the manifest.

**Step 3 -- Write tests:**
- File: `test/init.test.mjs` (add to existing file, or create if it doesn't exist)
- Add:

```javascript
import { describe, it, beforeEach, afterEach } from "node:test";
import assert from "node:assert/strict";
import { mkdtempSync, rmSync, writeFileSync, mkdirSync } from "node:fs";
import { join } from "node:path";
import { tmpdir } from "node:os";
import { matchesDetection, filterRelevantRules } from "../lib/init.mjs";

describe("matchesDetection with projectRoot", () => {
  let tmp;
  beforeEach(() => { tmp = mkdtempSync(join(tmpdir(), "brief-init-")); });
  afterEach(() => { rmSync(tmp, { recursive: true }); });

  it("matches Dockerfile when file exists", () => {
    writeFileSync(join(tmp, "Dockerfile"), "FROM node:20");
    assert.equal(matchesDetection(["Dockerfile"], {}, tmp), true);
  });

  it("returns false for Dockerfile when file missing", () => {
    assert.equal(matchesDetection(["Dockerfile"], {}, tmp), false);
  });

  it("matches fly.toml when file exists", () => {
    writeFileSync(join(tmp, "fly.toml"), "app = 'test'");
    assert.equal(matchesDetection(["fly.toml"], {}, tmp), true);
  });

  it("matches wrangler.toml when file exists", () => {
    writeFileSync(join(tmp, "wrangler.toml"), "name = 'test'");
    assert.equal(matchesDetection(["wrangler.toml"], {}, tmp), true);
  });

  it("matches wrangler.jsonc when file exists", () => {
    writeFileSync(join(tmp, "wrangler.jsonc"), "{}");
    assert.equal(matchesDetection(["wrangler.jsonc"], {}, tmp), true);
  });

  it("matches vercel.json when file exists", () => {
    writeFileSync(join(tmp, "vercel.json"), "{}");
    assert.equal(matchesDetection(["vercel.json"], {}, tmp), true);
  });

  it("matches pyproject.toml:django via frameworks", () => {
    assert.equal(
      matchesDetection(["pyproject.toml:django"], { frameworks: ["django"] }, tmp),
      true
    );
  });
});
```
