# S-014-T3: Delete templates/project-skills/

**Priority:** P1 | **Status:** in_progress | **Blocked By:** S-014-T1, S-014-T2

## What
Delete the `templates/project-skills/` directory and update any references to it in documentation or code.

## Why
The contents of `templates/project-skills/` have been relocated: Hono stack conventions → techstack.md rule template (T-001), Hono scaffold instructions → scaffold-module skill (T-002). The old directory has no installation path (`brief init` never processes it) and keeping it creates confusion about where templates live.

## Context
The directory contains two subdirectories:
- `templates/project-skills/hono-react-router-prisma/SKILL.md` — 166 lines of Hono conventions (now relocated to techstack.md concept)
- `templates/project-skills/hono-new-module/SKILL.md` — 97 lines of scaffold instructions (now relocated to scaffold-module skill)

Neither is wired into any code path. `lib/init.mjs` only reads from `templates/rules/` and `templates/project-structure/`. No imports, requires, or references to `templates/project-skills/` exist in any `.mjs` file.

## How

**Step 1 -- Verify no code references:**
```bash
grep -r "project-skills" lib/ skills/ templates/rules/ bin/ 2>/dev/null || echo "No code references"
grep -r "project-skills" documentation/ README.md AGENTS.md 2>/dev/null | head -20
```

**Step 2 -- Delete the directory:**
```bash
rm -rf templates/project-skills/
```

**Step 3 -- Update any documentation references found in Step 1:**
If grep found references in documentation files, update them to point to the new locations:
- `hono-react-router-prisma` → mention techstack.md template
- `hono-new-module` → mention scaffold-module skill

**Step 4 -- Verify:**
```bash
test -d templates/project-skills && echo "STILL EXISTS" || echo "deleted"
node --test
```
