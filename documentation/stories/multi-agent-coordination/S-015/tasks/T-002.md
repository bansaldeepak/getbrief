# S-015-T2: Agent Discipline Rule + brief init Distribution

**Priority:** P1 | **Status:** completed | **Blocked By:** --

## What

Create `rules/brief-cli-ops.md` — a concise agent discipline rule (~25 lines) that makes the brief CLI mandatory for all `documentation/` CRUD operations. Distribute it via `brief init` by adding it to the rules manifest.

## Why

Agents scaffold via `brief story create` then bypass with direct `Write`, leaving `tracker.yaml` stale and file formats inconsistent. A concise rule loaded via glob on `documentation/**` ensures agents know the ~8 commands they actually need.

## Context

- Rules are distributed by `brief init` — the manifest at `templates/rules/manifest.json` controls which rules are copied
- Existing rules in `rules/` follow a pattern: short, glob-targeted, terse bullet points
- The rule must fire on `documentation/**` glob so it auto-loads when agents touch story/todo/decision files
- The rule should list the commands agents need, not the full CLI reference (~40+ commands)
- CEO review decided: start with logging (informational), not enforcement. The rule is advisory.

Current rules in `rules/`:
```
brief.md, coding-standards.md, db-safety.md, documentation-standards.md,
git-workflow.md, observability.md
```

Current templates in `templates/rules/`:
```
backend-standards.md, coding-style.md, critical-thinking.md, deployment.md,
first-principles.md, frontend-standards.md, git-workflow.md, manifest.json,
observability-wiring.md, product-analytics.md, techstack.md
```

## How

**Step 1 — Create the rule file:**
- File: `rules/brief-cli-ops.md` (new)
- Content should include:
  - Glob: `documentation/**`
  - Mandatory CLI commands for CRUD: `brief story create`, `brief story task create`, `brief todo create`, `brief decision create`, `brief story update`, `brief story task update`, `brief todo update`, `brief decision update`
  - Explicit prohibition: never use direct `Write`/`writeFileSync` to create or modify files in `documentation/stories/`, `documentation/todo/`, `documentation/decisions/`
  - Exception: `documentation/memory/` files are created via `brief memory create`
  - Keep it under 30 lines — agents ignore long rules

**Step 2 — Add to templates for distribution:**
- File: `templates/rules/manifest.json`
- Read the current manifest structure and add `brief-cli-ops.md` entry
- The manifest controls which rules `brief init` copies to projects

**Step 3 — Create the template copy:**
- File: `templates/rules/brief-cli-ops.md` (new) — same content as `rules/brief-cli-ops.md`
- `brief init` copies from `templates/rules/` to the target project's `.claude/rules/`

**Step 4 — Verify:**
```bash
test -f rules/brief-cli-ops.md && echo "rule exists"
test -f templates/rules/brief-cli-ops.md && echo "template exists"
cat templates/rules/manifest.json | grep brief-cli-ops
wc -l rules/brief-cli-ops.md  # should be <30
```

## Files to Read First
