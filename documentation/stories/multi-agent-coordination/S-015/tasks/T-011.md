# S-015-T11: Counter State in brief status

**Priority:** P2 | **Status:** done | **Blocked By:** S-015-T5

## What

Show the shared counter state in `brief status` output so developers can debug ID allocation and see what IDs have been reserved.

## Why

PRD R11 — counter visibility is a debugging aid. When agents misbehave or IDs seem wrong, `brief status` should show the current counter values so developers can diagnose without reading `.git/brief-counter` directly.

## Context

`brief status` is implemented in `lib/commands/status.mjs`. It currently shows counts by type and status. After this task, it also shows the shared counter state when running inside a git repo.

The counter file is at `.git/brief-counter` (via `gitCommonDir`). Format:
```json
{
  "story": 15,
  "todo": 8,
  "decision": 3,
  "task:S-012": 7
}
```

The display should be concise — something like:
```
Counter (.git/brief-counter):
  story: 15, todo: 8, decision: 3
  task:S-012: 7, task:S-015: 3
```

For non-git projects, skip the counter section entirely.

## How

**Step 1 — Read status.mjs:**
- File: `lib/commands/status.mjs`
- Understand the current output format and where to add the counter section

**Step 2 — Add counter display:**
- Import `gitCommonDir` from `../tracker.mjs`
- After the existing status output, add:

```javascript
const gitDir = gitCommonDir(root);
if (gitDir) {
  const counterPath = join(gitDir, "brief-counter");
  if (existsSync(counterPath)) {
    try {
      const counter = JSON.parse(readFileSync(counterPath, "utf8"));
      console.log("\nCounter (.git/brief-counter):");
      const types = Object.entries(counter).filter(([k]) => !k.startsWith("task:"));
      const tasks = Object.entries(counter).filter(([k]) => k.startsWith("task:"));
      if (types.length) console.log("  " + types.map(([k, v]) => `${k}: ${v}`).join(", "));
      if (tasks.length) console.log("  " + tasks.map(([k, v]) => `${k}: ${v}`).join(", "));
    } catch {}
  }
}
```

**Step 3 — Verify:**
```bash
brief status
# Should show counter section if .git/brief-counter exists
```
