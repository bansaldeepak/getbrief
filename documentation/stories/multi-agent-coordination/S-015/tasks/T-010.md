# S-015-T10: Integration Tests — Cross-Process Lock Contention

**Priority:** P1 | **Status:** pending | **Blocked By:** S-015-T3, S-015-T4, S-015-T5, S-015-T6, S-015-T7, S-015-T8, S-015-T9

## What

Write 4 integration tests that verify cross-process behavior: lock contention, parallel story creation, task numbering under contention, and stale lock recovery. These test the full system end-to-end with actual child processes.

## Why

Unit tests (T3-T9) verify individual functions in isolation. Integration tests verify that the lock actually serializes concurrent processes — the whole point of this feature. Without these, we'd ship untested concurrency behavior.

## Context

Integration tests use `node:child_process` to fork actual brief processes. The test pattern:
1. Set up a temp git repo (with tracker.yaml, counter, etc.)
2. Fork N child processes that each run a brief command
3. Wait for all to complete
4. Verify results (unique IDs, correct counter state, no corruption)

Test runner: `node --test` (built-in). Test file: `test/tracker.test.mjs` (append to existing, or separate `test/tracker-integration.test.mjs` if the file is getting large).

The child processes need a real git repo because `gitCommonDir` calls `git rev-parse`. Use `execFileSync('git', ['init'])` in temp dir.

**Important**: `Atomics.wait` requires `--allow-shared-buffer` flag in some Node.js configs. If tests fail with SharedArrayBuffer errors, the test command may need this flag.

## How

**Step 1 — Integration test: lock contention (two processes):**
```javascript
describe("integration: lock contention", () => {
  it("two processes serialize through lock", () => {
    // Setup: temp dir, git init, tracker.yaml with known state
    // Fork two child processes that each:
    //   acquireLock → sleep 100ms → write marker to a shared file → releaseLock
    // Wait for both to complete
    // Read shared file — markers should be sequential, not interleaved
  });
});
```

Use a helper script that the test forks:
```javascript
// test/helpers/lock-worker.mjs
import { acquireLock, releaseLock, gitCommonDir } from "../../lib/tracker.mjs";
const root = process.argv[2];
const gitDir = gitCommonDir(root);
const lockPath = acquireLock(gitDir);
// write PID to shared log file
Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, 100);
releaseLock(lockPath);
```
