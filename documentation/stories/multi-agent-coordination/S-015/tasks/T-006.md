# S-015-T6: Refactor nextId to Delegate to allocateId

**Priority:** P0 | **Status:** done | **Blocked By:** S-015-T5

## What

Refactor `nextId()` in `lib/tracker.mjs` so it delegates to `allocateId()` when inside a git repo, and falls back to the existing `max+1` logic for non-git projects. Add unit tests for both paths.

## Why

`nextId()` is the public API called by all creation commands (`story.mjs:403`, `item.mjs:264`, `cli.mjs:212`). After T3-T5 added lock primitives, atomic writes, and the counter, `nextId` needs to route through them. Non-git projects must keep working with the old logic (no lock, no counter).

## Context

Current `nextId()` signature at `lib/tracker.mjs:54`:
```javascript
export function nextId(items, type, projectRoot)
```

After this task, `nextId` will:
1. Call `gitCommonDir(projectRoot)` (added in T3)
2. If git dir exists: call `withLock(gitDir, () => allocateId(projectRoot, gitDir, type))` (added in T3/T5)
3. If no git dir: run the existing `max+1` logic (current lines 54-109)

The existing `max+1` logic stays in `nextId` as the fallback path. The `allocateId` path (T5) handles the git case.

**Important**: `nextId` currently takes `items` as its first parameter. After this refactor, the git path reads items internally (via `allocateId` → `readTracker`), but the fallback path still uses the passed `items`. The signature stays the same for backward compat — callers don't change.

```javascript
export function nextId(items, type, projectRoot) {
  const cfg = TYPE_CONFIG[type];
  if (!cfg) throw new Error(`Unknown type: ${type}`);

  // Git path: use shared counter with lock
  if (projectRoot) {
    const gitDir = gitCommonDir(projectRoot);
    if (gitDir) {
      return withLock(gitDir, () => allocateId(projectRoot, gitDir, type));
    }
  }

  // Non-git fallback: existing max+1 logic
  const prefix = cfg.prefix;
  const re = new RegExp(`^${prefix}-(\\d+)`, "i");

  const trackerNums = items
    .filter((i) => i.type === type)
    .map((i) => {
      const match = i.id.match(re);
      return match ? parseInt(match[1], 10) : 0;
    });

  const fsNums = [];
  if (projectRoot) {
    // ... existing filesystem scan logic (lines 72-104, unchanged)
  }

  const allNums = [...trackerNums, ...fsNums];
  const max = allNums.length > 0 ? Math.max(...allNums) : 0;
  return `${prefix}-${String(max + 1).padStart(3, "0")}`;
}
```

Keep the filesystem scan logic in the fallback path exactly as-is. Do NOT delete it — non-git projects depend on it.
