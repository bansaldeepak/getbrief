# S-015-T5: allocateId, seedCounter, gitCommonDir Counter Operations

**Priority:** P0 | **Status:** pending | **Blocked By:** S-015-T3, S-015-T4

## What

Add `allocateId()` and `seedCounter()` functions to `lib/tracker.mjs`. These read/increment the shared counter file at `.git/brief-counter`, with atomic writes. On first use (counter file missing), `seedCounter()` bootstraps from `tracker.yaml` + filesystem scan. Add unit tests.

## Why

The shared counter in `.git/brief-counter` is the core of atomic ID allocation. It replaces the racy `max+1` logic in `nextId()`. The counter is shared across all worktrees because `.git/` (via `git rev-parse --git-common-dir`) is the same physical directory for all worktrees.

## Context

Counter file format (`.git/brief-counter`):
```json
{
  "story": 15,
  "todo": 8,
  "decision": 3,
  "research": 1,
  "audit": 0,
  "bug": 2,
  "memory": 4,
  "task:S-012": 7,
  "task:S-015": 3
}
```

Values store the **last allocated number** (not next). `allocateId("story")` reads `story: 15`, writes `story: 16`, returns 16.

Seeding logic (on first access, inside lock):
1. Read tracker.yaml — extract max ID per type using same regex as current `nextId()`
2. Scan filesystem directories — same as current `nextId()` safety net (lines 70-108)
3. Take `Math.max()` of both per type
4. Write `.git/brief-counter` atomically (.tmp + rename)

The counter file itself must use atomic writes (.tmp + rename) — eng review D5 found this was missing from original TRD.

`gitCommonDir()` was added in T3. `acquireLock`/`releaseLock`/`withLock` were added in T3. `renameSync` import was added in T3/T4.

The `COUNTER_FILE` constant should be: `const COUNTER_FILE = "brief-counter";`

## How

**Step 1 — Add `readCounter(gitDir)`:**
- File: `lib/tracker.mjs`
```javascript
function readCounter(gitDir) {
  const counterPath = join(gitDir, COUNTER_FILE);
  try {
    return JSON.parse(readFileSync(counterPath, "utf8"));
  } catch (err) {
    if (err.code === "ENOENT") return null;
    console.error("Warning: brief counter corrupted, re-seeding from tracker");
    return null;
  }
}
```

**Step 2 — Add `writeCounter(gitDir, counter)`:**
```javascript
function writeCounter(gitDir, counter) {
  const counterPath = join(gitDir, COUNTER_FILE);
  const tmpPath = counterPath + ".tmp";
  writeFileSync(tmpPath, JSON.stringify(counter, null, 2) + "\n");
  renameSync(tmpPath, counterPath);
}
```

**Step 3 — Add `seedCounter(projectRoot, gitDir)`:**
```javascript
export function seedCounter(projectRoot, gitDir) {
  const items = readTracker(projectRoot);
  const counter = {};

  for (const type of Object.keys(TYPE_CONFIG)) {
    const cfg = TYPE_CONFIG[type];
    const re = new RegExp(`^${cfg.prefix}-(\\d+)`, "i");

    const trackerNums = items
      .filter((i) => i.type === type)
      .map((i) => { const m = i.id.match(re); return m ? parseInt(m[1], 10) : 0; });

    const fsNums = [];
    // Same filesystem scan logic as current nextId() lines 70-108
    // ... (copy the directory scan logic from nextId)

    const allNums = [...trackerNums, ...fsNums];
    counter[type] = allNums.length > 0 ? Math.max(...allNums) : 0;
  }

  writeCounter(gitDir, counter);
  return counter;
}
```

**Step 4 — Add `allocateId(projectRoot, gitDir, type)`:**
```javascript
export function allocateId(projectRoot, gitDir, type) {
  const cfg = TYPE_CONFIG[type];
  if (!cfg) throw new Error(`Unknown type: ${type}`);

  let counter = readCounter(gitDir);
  if (!counter) {
    counter = seedCounter(projectRoot, gitDir);
  }

  // Safety: also check tracker max in case manual edits pushed tracker ahead
  const items = readTracker(projectRoot);
  const re = new RegExp(`^${cfg.prefix}-(\\d+)`, "i");
  const trackerMax = items
    .filter((i) => i.type === type)
    .map((i) => { const m = i.id.match(re); return m ? parseInt(m[1], 10) : 0; })
    .reduce((a, b) => Math.max(a, b), 0);

  const counterVal = counter[type] || 0;
  const next = Math.max(counterVal, trackerMax) + 1;
  counter[type] = next;
  writeCounter(gitDir, counter);

  return `${cfg.prefix}-${String(next).padStart(3, "0")}`;
}
```
