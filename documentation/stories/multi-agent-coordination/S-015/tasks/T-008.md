# S-015-T8: Fix Task Numbering Race — Per-Story Counter

**Priority:** P1 | **Status:** pending | **Blocked By:** S-015-T5, S-015-T7

## What

Replace the directory-scan task numbering in `lib/commands/story.mjs` (line 228) with a per-story counter in `.git/brief-counter`. Add a unit test.

## Why

Task numbering at `story.mjs:228` has the same race as story IDs — two agents adding tasks to the same story simultaneously both scan `readdirSync`, find the same max, and create the same `T-NNN.md`. CEO review D11 identified this as needing the same counter fix.

## Context

Current task numbering at `story.mjs:228-233`:
```javascript
const existing = readdirSync(join(root, tasksDir))
  .filter((f) => /^T-\d+\.md$/i.test(f))
  .map((f) => parseInt(f.match(/T-(\d+)/i)[1], 10));
const nextNum = existing.length > 0 ? Math.max(...existing) + 1 : 1;
const taskNum = String(nextNum).padStart(3, "0");
const taskId = `${storyId}-T${nextNum}`;
const taskFile = `T-${taskNum}.md`;
```

After this task, the counter file `.git/brief-counter` will have per-story keys like `task:S-015` storing the last allocated task number for that story.

The `storyTaskCreate` function is already wrapped in `withLockIfGit` from T7. The task numbering just needs to read/write the counter instead of scanning the directory.

For non-git fallback: keep the directory scan as-is (no counter available).

## How

**Step 1 — Add `allocateTaskNum(projectRoot, gitDir, storyId)` to tracker.mjs:**
- File: `lib/tracker.mjs`
```javascript
export function allocateTaskNum(projectRoot, gitDir, storyId) {
  let counter = readCounter(gitDir);
  if (!counter) counter = seedCounter(projectRoot, gitDir);

  const key = `task:${storyId}`;
  const current = counter[key] || 0;

  // Safety: also check filesystem in case manual files were added
  const dirs = {
    story: "documentation/stories",
  };
  let fsMax = 0;
  // Scan all feature dirs for this story's tasks dir
  const storiesDir = join(projectRoot, dirs.story);
  if (existsSync(storiesDir)) {
    for (const feature of readdirSync(storiesDir)) {
      const storyDir = join(storiesDir, feature, storyId, "tasks");
      if (existsSync(storyDir)) {
        for (const f of readdirSync(storyDir)) {
          const m = f.match(/^T-(\d+)\.md$/i);
          if (m) fsMax = Math.max(fsMax, parseInt(m[1], 10));
        }
      }
    }
  }

  const next = Math.max(current, fsMax) + 1;
  counter[key] = next;
  writeCounter(gitDir, counter);
  return next;
}
```

const gitDir = gitCommonDir(root);
