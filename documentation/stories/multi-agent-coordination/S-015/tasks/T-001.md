# S-015-T1: MEMORY.md Harness Snippet + Discover Phase 6

**Priority:** P1 | **Status:** completed | **Blocked By:** --

## What

Add a harness snippet to the MEMORY.md template so agents use `brief memory` commands instead of reading raw memory files. Also add Phase 6 (auto-persist) to the discover skill so DISCOVERY.md is always written to the feature folder.

## Why

Agents currently read raw `documentation/memory/*.md` files, bloating context with full file contents. The `brief memory list`/`brief memory show` commands return concise summaries. Without a harness snippet, agents don't know these commands exist.

Separately, the discover skill produces findings in conversation but doesn't persist them — the user had to manually remind to create DISCOVERY.md. This violates brief's project-local memory premise.

## Context

- The AGENTS.md harness pattern (`<!-- brief:auto -->` markers) already exists and is the precedent for injecting agent guidance
- The MEMORY.md template lives at `templates/project-structure/MEMORY.md` and is copied by `brief init`
- The discover skill is at `.claude/skills/brief/discover/SKILL.md`
- Feedback memory `documentation/memory/feedback_discover-must-persist.md` documents this gap

## How

**Step 1 — Add harness snippet to MEMORY.md template:**
- File: `templates/project-structure/MEMORY.md`
- Add a section at the top (after any existing header) with guidance:
  ```markdown
  <!-- brief:memory-harness -->
  ## Memory Commands

  Use `brief memory` commands instead of reading files directly:
  - `brief memory list` — concise index of all memories
  - `brief memory show <name>` — view a specific memory
  - `brief memory create <name> --type=<type>` — create a new memory
  - `brief memory update <name>` — update an existing memory

  Do NOT read `documentation/memory/*.md` files directly — use the commands above.
  <!-- /brief:memory-harness -->
  ```

**Step 2 — Add Phase 6 to discover skill:**
- File: `.claude/skills/brief/discover/SKILL.md`
- After the existing final phase, add:
  ```markdown
  ### Phase 6: Persist

  Write the discovery summary to `documentation/stories/<feature>/DISCOVERY.md`. The feature folder
  should already exist (created at branch check). If it doesn't, create it.

  The DISCOVERY.md must contain all findings from the discovery conversation — forcing questions,
  brainstorm lenses, assumptions, pre-mortem, experiments, and recommended path. Conversation
  output alone is not sufficient — it's lost when the session ends.
  ```

**Step 3 — Verify:**
```bash
grep -c "brief:memory-harness" templates/project-structure/MEMORY.md
grep -c "Phase 6" .claude/skills/brief/discover/SKILL.md
```

## Files to Read First

- `templates/project-structure/MEMORY.md` — current template content
- `.claude/skills/brief/discover/SKILL.md` — current skill phases
- `documentation/memory/feedback_discover-must-persist.md` — feedback that motivated this
