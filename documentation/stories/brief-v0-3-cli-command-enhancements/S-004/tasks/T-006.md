# S-004-T6: Task completion clears current_task and sets last_task

**Status:** completed
**Priority:** P1
**Blocked By:** —

## Description

storyTaskUpdate on status=completed sets current_task=null, last_task=taskId on parent story

## Implementation Notes

**File:** `brief/lib/commands/story.mjs` — `storyTaskUpdate()` (around line 267)

Current code handles `in_progress` → sets `current_task`. Add completion handling:

```js
if (["completed", "done"].includes(updates.status)) {
  const items = readTracker(root);
  const storyIdx = items.findIndex((i) => i.id === storyId);
  if (storyIdx !== -1) {
    items[storyIdx].current_task = null;
    items[storyIdx].last_task = taskId;
    writeTracker(root, items);
  }
}
```

- New field `last_task` on story tracker entries (optional, null by default)
- No migration needed — YAML is schema-flexible, new field appears only on stories that have completed tasks
- No auto-advance — model explicitly sets next task via `status=in_progress`
