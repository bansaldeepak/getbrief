# S-004-T5: Standardize output — all creates print path: as final line

**Status:** pending
**Priority:** P1
**Blocked By:** S-004-T1

## Description

All create commands print consistent format ending with path: repo-relative-path

## Implementation Notes

**Files:** `brief/lib/commands/item.mjs`, `story.mjs`, `log.mjs`

Standardize all create command output to this format:
```
✓ Created <ID>: <title>
  <metadata lines...>
path: <repo-relative-path>
```

Changes per command:

| Command | Current last line | New last line |
|---------|-------------------|---------------|
| `item create` | `→ dir/ID.md` | `path: documentation/<type>/ID.md` |
| `story create` | `→ dir/tasks/` | `path: documentation/stories/.../story.md` |
| `story task create` | `→ dir/T-NNN.md` | `path: documentation/stories/.../tasks/T-NNN.md` |
| `log add` | `→ documentation/logs/file.md` | `path: documentation/logs/file.md` |

Keep existing `→` info lines (they're useful for humans) but add `path:` as the definitive final line.

Consumer pattern: `brief todo create "X" | tail -1 | cut -d' ' -f2-`
