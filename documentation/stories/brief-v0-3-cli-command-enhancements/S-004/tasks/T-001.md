**Status:** pending

## Description

Create brief/lib/body.mjs — readBody(rawArgs) that extracts --body= flag or reads stdin

## Implementation Notes

Create `brief/lib/body.mjs` exporting one async function:

```js
export async function readBody(rawArgs) → string | null
```

Logic:
1. Scan `rawArgs` for `--body=<content>` — return content string
2. If no `--body` and `!process.stdin.isTTY` — read all stdin chunks, return trimmed
3. Otherwise return `null` (caller uses template)

Precedence: `--body` wins if both flag and stdin are present.

Pattern exists in `lib/commands/context.mjs` (`readStdin()`) — extract and generalize. The context command itself stays untouched.
