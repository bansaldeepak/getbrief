# S-004-T3: Item create accepts body content

**Status:** in_progress
**Priority:** P1
**Blocked By:** S-004-T1

## Description

Update itemCreate (todo, decision, research, audit) to inject body into template replacing placeholder comments

## Implementation Notes

**File:** `brief/lib/commands/item.mjs` — `itemCreate()`

- Import `readBody` from `../body.mjs`
- Make `itemCreate` async, call `const body = await readBody(rawArgs)`
- After generating template string from `TEMPLATES[type](...)`, if body non-null:
  - Replace the first `<!-- ... -->` comment in the primary content section

Target placeholder per type:
| Type | Section | Placeholder |
|------|---------|-------------|
| todo | `## Why` | `<!-- Why this matters. What breaks or degrades without it. -->` |
| decision | `## Context` | `<!-- What prompted this decision. The problem or fork in the road. -->` |
| research | `## Motivation` | `<!-- Why this matters now. What decision or work is blocked without the answer. -->` |
| audit | `## Method` | `<!-- How the audit will be conducted. -->` |

Implementation: simple string replace on the exact placeholder text (these are static template strings we control).

- Make `itemCommand` async, update `cli.mjs` to `await` it

## Verification

- [ ] `echo "Context here" | brief decision create "Choice A"` → Context section filled
- [ ] `brief research create "test" --body="Blocked on Y"` → Motivation section filled
