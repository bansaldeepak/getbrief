# S-003-T6: Update rules + remove standalone codegraph rules

**Priority:** P2 | **Status:** pending | **Blocked By:** S-003-T3, S-003-T4

## What
Update `rules/brief.md` to document the new `brief query` and `brief context` commands. Remove the standalone `rules/codegraph.md` (its guidance is subsumed by brief.md now that codegraph is bundled).

## Why
Agent rules drive tool selection. If `rules/brief.md` doesn't mention `brief query`, agents won't use it — they'll keep falling back to `codegraph explore` or grep. The standalone `rules/codegraph.md` becomes misleading once codegraph is bundled inside brief.

## Context
- `rules/brief.md` currently documents: search, story, todo, decision, research, audit, log, tracker, init, migrate, serve
- `rules/codegraph.md` currently tells agents to use `codegraph_search`, `codegraph_context`, `codegraph_callers`, etc. as standalone tools
- After this change: agents use `brief query` for code lookups, `brief context` for graduated context
- `codegraph explore` MCP tool via serve.mjs still works (for agents that have it configured) — but the rules should point to `brief query` as the primary interface
- Keep the rules concise — agents need to know WHEN to use each command, not HOW it works internally

## How

**Step 1 -- Update rules/brief.md:**
- File: `rules/brief.md` (in `~/.agents/rules/brief.md`)
- What: Add `query` and `context` commands to the table/descriptions

Add to the command reference section:

```markdown
## Code + Doc Search

| Command | Use For |
|---------|---------|
| `brief query <q>` | Find code symbols AND docs in one call |
| `brief query --callers <q>` | Show what calls a function |
| `brief query --impact <q>` | Show blast radius of changing a symbol |
| `brief query --json <q>` | Structured output for programmatic use |

Use `brief query` as the DEFAULT lookup — it covers both code and docs.
Only use `brief search` when you specifically need doc-only results.

## Graduated Context

| Command | Use For |
|---------|---------|
| `echo "body" \| brief context graduate "title"` | Save cross-cutting knowledge |
| `brief context list` | See all graduated context |
| `brief context <query>` | Search graduated context |

Graduate context when you discover knowledge that:
- Applies across multiple features/stories
- Would be lost if only in conversation
- Future agents need to know
```

**Step 2 -- Remove rules/codegraph.md:**
- File: `~/.agents/rules/codegraph.md`
- What: Delete this file (its content is replaced by brief.md's query section)

Note: The global CLAUDE.md still has a "## CodeGraph" section that references MCP tools — that stays because it applies to projects NOT using brief. But for brief-managed projects, `brief query` is the primary interface.

**Step 3 -- Verify:**
```bash
# Confirm rules/brief.md exists and has the new sections
grep -l "brief query" ~/.agents/rules/brief.md

# Confirm codegraph.md is gone
ls ~/.agents/rules/codegraph.md  # should not exist
```
