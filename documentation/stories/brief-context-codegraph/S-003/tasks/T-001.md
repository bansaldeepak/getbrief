# S-003-T1: Add codegraph dependency + create code-index.mjs interface

**Priority:** P0 | **Status:** pending | **Blocked By:** --

## What
Add `@colbymchenry/codegraph` as an npm dependency and create `lib/code-index.mjs` -- an interface layer that wraps the codegraph JS API. This module is the single import point for all codegraph queries across the brief codebase.

## Why
Every other task depends on this interface. Without it, there's no abstraction between brief and the third-party codegraph package. The interface enables graceful fallback (no index = null handle) and future backend swaps without changing callers.

## Context
- `@colbymchenry/codegraph` v1.5.0 ships both a CLI binary and a JS API (`npm-sdk.js`)
- The JS API exposes: `CodeGraph.openSync(root)` -> returns a graph handle with `searchNodes(query)`, `getCallers(id)`, `getImpactRadius(id)`
- Performance: DB open 130ms (once), searchNodes 19ms, getCallers/getImpactRadius <1ms
- `serve.mjs` is a long-lived MCP server -- the cached DB handle can go stale if `brief init --reindex` rebuilds the DB while the server is running. Solution: check file mtime before each query; reopen if changed.

## How

**Step 1 -- Add dependency:**
- File: `package.json`
- What: Add `@colbymchenry/codegraph` to dependencies

```json
{
  "dependencies": {
    "@colbymchenry/codegraph": "^1.5.0",
    "@modelcontextprotocol/sdk": "^1.12.1",
    "yaml": "^2.9.0"
  }
}
```

Then run: `npm install`

**Step 2 -- Create interface module:**
- File: `lib/code-index.mjs` (NEW)
- Pattern: Export `open(root)`, `search(handle, query)`, `callers(handle, nodeId)`, `impact(handle, nodeId)`
- Graceful null: if `.codegraph/codegraph.db` doesn't exist, `open()` returns `null`
- Mtime refresh: store the DB file's mtimeMs on open; before each query, stat the file; if mtime changed, close and reopen

```javascript
import { existsSync, statSync } from "node:fs";
import { join } from "node:path";

let cachedHandle = null;
let cachedRoot = null;
let cachedMtime = 0;

function getDbPath(root) {
  return join(root, ".codegraph/codegraph.db");
}

export function open(root) {
  const dbPath = getDbPath(root);
  if (!existsSync(dbPath)) return null;

  try {
    const { default: CodeGraph } = await import("@colbymchenry/codegraph");
    const mtime = statSync(dbPath).mtimeMs;
    cachedHandle = CodeGraph.openSync(root);
    cachedRoot = root;
    cachedMtime = mtime;
    return cachedHandle;
  } catch {
    return null;
  }
}

export function getHandle(root) {
  const dbPath = getDbPath(root);
  if (!existsSync(dbPath)) return null;

  const currentMtime = statSync(dbPath).mtimeMs;
  if (cachedHandle && cachedRoot === root && cachedMtime === currentMtime) {
    return cachedHandle;
  }
  // Reopen on mtime change or first access
  return open(root);
}

export function search(handle, query) {
  if (!handle) return [];
  try {
    return handle.searchNodes(query);
  } catch {
    return [];
  }
}

export function callers(handle, nodeId) {
  if (!handle) return [];
  try {
    return handle.getCallers(nodeId);
  } catch {
    return [];
  }
}

export function impact(handle, nodeId) {
  if (!handle) return [];
  try {
    return handle.getImpactRadius(nodeId);
  } catch {
    return [];
  }
}
```
