# S-003-T2: Extend init.mjs with codegraph setup

**Priority:** P0 | **Status:** pending | **Blocked By:** S-003-T1

## What
Modify `lib/init.mjs` to: (1) run `codegraph init -i` via the bundled CLI binary when `.codegraph/` doesn't exist, (2) scaffold `documentation/context/` directory, (3) add `.codegraph/` to the project's `.gitignore`. Also add `--reindex` flag support.

## Why
Without this, users must manually install and run codegraph separately. `brief init` should be the single setup command that gives you everything. The `--reindex` flag provides recovery when the index is corrupted or stale.

## Context
- The codegraph CLI binary lives at `brief/node_modules/.bin/codegraph` (installed by T-001)
- Since brief is globally installed (`npm link`), the binary must be resolved via `import.meta.url` -- NOT relative to the user's cwd
- `lib/init.mjs` already uses `import.meta.url` for template resolution (line 10-11): `const __dirname = dirname(fileURLToPath(import.meta.url));`
- The correct relative path from `lib/` to the bin: `join(__dirname, "../node_modules/.bin/codegraph")`
- `codegraph init -i` is interactive (shows progress). For `brief init` we want non-interactive: pipe stdout/stderr through
- If the project has no JS/TS files, `codegraph init` may fail -- catch and warn, don't abort init

**Step 2 -- Add codegraph init logic:**
- File: `lib/init.mjs`
- What: After file scaffolding, check for `.codegraph/` and run init if missing

```javascript
import { execSync } from "node:child_process";

const CODEGRAPH_BIN = join(__dirname, "../node_modules/.bin/codegraph");

// Inside initProject(), after file scaffolding:
function initCodegraph(projectRoot, opts = {}) {
  const codegraphDir = join(projectRoot, ".codegraph");
  
  if (opts.reindex) {
    // --reindex: delete and rebuild
    if (existsSync(codegraphDir)) {
      const { rmSync } = await import("node:fs");
      rmSync(codegraphDir, { recursive: true });
    }
  }
  
  if (!existsSync(codegraphDir)) {
    try {
      execSync(`"${CODEGRAPH_BIN}" init -i "${projectRoot}"`, {
        stdio: "inherit",
        timeout: 60000,
      });
      return "created";
    } catch (e) {
      console.warn("Warning: codegraph init failed (project may have no indexable files).");
      // Clean up partial directory if it exists
      if (existsSync(codegraphDir)) {
        const { rmSync } = await import("node:fs");
        rmSync(codegraphDir, { recursive: true });
      }
      return "skipped";
    }
  }
  return "exists";
}
```

```javascript
function ensureGitignore(projectRoot) {
  const gitignorePath = join(projectRoot, ".gitignore");
  const entry = ".codegraph/";
  if (existsSync(gitignorePath)) {
    const content = readFileSync(gitignorePath, "utf8");
    if (!content.includes(entry)) {
      appendFileSync(gitignorePath, `\n${entry}\n`);
    }
  } else {
    writeFileSync(gitignorePath, `${entry}\n`);
  }
}
```
