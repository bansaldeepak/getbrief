# S-003-T5: Route serve.mjs through code-index.mjs

**Priority:** P1 | **Status:** pending | **Blocked By:** S-003-T1

## What
Replace the direct `DatabaseSync` open in `serve.mjs` with an import of `code-index.mjs`. The MCP server tools that query codegraph now go through the interface layer.

## Why
R16 requires a single abstraction point for all codegraph access. Currently `serve.mjs` opens the SQLite DB directly (`new DatabaseSync(...)`) — a separate code path from what `brief query` will use. Routing through `code-index.mjs` gives us: (1) mtime-based handle refresh (the server is long-lived), (2) one place to swap backends, (3) consistent error handling.

## Context
- `serve.mjs` line 48: `const CODEGRAPH_DB = join(ROOT, ".codegraph/codegraph.db");`
- `serve.mjs` line 53-55: `const cgDB = existsSync(CODEGRAPH_DB) ? new DatabaseSync(CODEGRAPH_DB, { readOnly: true }) : null;`
- The existing MCP tools use `cgDB.prepare(...).all(...)` to query the SQLite DB directly
- After this change, they'll use `search(handle, query)`, `callers(handle, id)`, `impact(handle, id)` from code-index.mjs
- The mtime refresh in code-index.mjs handles the case where `brief init --reindex` rebuilds while server is running
- The `getHandle(root)` function checks mtime on every call — perfect for long-lived server

## How

**Step 1 -- Remove direct DB access:**
- File: `serve.mjs`
- What: Remove the `DatabaseSync` import and direct DB open

Remove:
```javascript
import { DatabaseSync } from "node:sqlite";
// ...
const CODEGRAPH_DB = join(ROOT, ".codegraph/codegraph.db");
// ...
const cgDB = existsSync(CODEGRAPH_DB) ? new DatabaseSync(CODEGRAPH_DB, { readOnly: true }) : null;
```

**Step 2 -- Import code-index.mjs:**
- File: `serve.mjs`
- What: Import the interface

```javascript
import { getHandle, search, callers, impact } from "./lib/code-index.mjs";
```

**Step 3 -- Replace tool implementations:**
- File: `serve.mjs`
- What: Update each MCP tool that queries codegraph to use the interface

Before (pattern used in serve.mjs tools):
```javascript
if (!cgDB) return { content: [{ type: "text", text: "No codegraph index" }] };
const results = cgDB.prepare("SELECT ...").all(query);
```

After:
```javascript
const handle = getHandle(ROOT);
if (!handle) return { content: [{ type: "text", text: "No codegraph index" }] };
const results = search(handle, query);
```

For callers/impact tools:
```javascript
const handle = getHandle(ROOT);
if (!handle) return { content: [{ type: "text", text: "No codegraph index" }] };
const results = callers(handle, nodeId);  // or impact(handle, nodeId)
```

**Step 4 -- Verify:**
```bash
# Start the MCP server, ensure tools still work
brief serve &
# Use MCP inspector or direct tool call to verify
# Then stop the server
kill %1
```
