# S-005-T1: Update project-structure templates — remove knowledge graph refs

**Priority:** P0 | **Status:** completed | **Blocked By:** --

## What
Update the 3 template files in `templates/project-structure/` to remove all knowledge graph references and replace with `brief` CLI commands. These templates are what `brief init` copies into new projects.

## Why
New projects scaffolded by `brief init` currently get instructions pointing at MCP tools (`knowledge_search`, `knowledge_context`) and a CLI (`knowledge-graph`) that don't exist. Agents following these templates waste tokens and hit dead ends.

## Context
- `brief` is the project management CLI (shipped in S-002, S-003, S-004)
- The knowledge graph was never operational (S-003 retro confirmed "binary not found")
- `brief init` copies these templates verbatim into new projects
- `.codegraph/` (code index) is separate and stays — only `.project/knowledge.db` is being removed

## How

**Step 1 — Update `templates/project-structure/MEMORY.md`:**
- File: `templates/project-structure/MEMORY.md`
- Replace entire content with:

```markdown
# Project Memory

Memory is stored in `memory/` as individual markdown files with frontmatter.

## How to access

**Primary** — use `brief` CLI:
```bash
brief search "<query>"          # search all memory
brief status                    # summary of project state
```

**Fallback** — read files directly:
- `memory/*.md` — individual memory files
- This file (`MEMORY.md`) — lightweight index

## Index

<!-- One line per memory, under ~40 lines total. Format: -->
<!-- - [slug](memory/slug.md) — one-line summary -->
```

**Step 2 — Update `templates/project-structure/AGENTS.md`:**
- File: `templates/project-structure/AGENTS.md`
- Remove the `.project/` entry and `knowledge.db` line from the Project Structure section
- Remove `(knowledge graph is primary read path)` from the MEMORY.md comment
- Replace with brief-aware structure

New Project Structure section:
```
## Project Structure

\```
documentation/
  stories/         # feature folders (PRD, TRD, story, tasks)
  decisions/       # DEC-NNN.md files
  todo/            # TODO-NNN.md files
  logs/            # one file per log entry
  memory/          # agent memory files
  context/         # graduated cross-cutting knowledge
tracker.yaml       # structured source of truth for all items
PROJECT-TRACKER.md # generated — active items only
MEMORY.md          # memory index (brief search is primary read path)
\```
```

**Step 3 — Update `templates/project-structure/tracker.yaml`:**
- File: `templates/project-structure/tracker.yaml`
- Replace lines 8-10 (the `knowledge-graph` CLI comments) with `brief` commands:

```yaml
# CLI: brief story create <title>
#      brief todo create <title>
#      brief tracker generate  (regenerates PROJECT-TRACKER.md from this file)
```
