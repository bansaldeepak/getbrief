# S-005-T4: Update provider configs + global AGENTS.md — remove knowledge graph

**Priority:** P0 | **Status:** completed | **Blocked By:** --

## What
Remove knowledge graph references from `providers/claude.md` and the global `AGENTS.md` Memory Checkpoints section. Then rebuild provider configs via `build.sh`.

## Why
The global config files loaded into every session still tell Claude to use `knowledge_context` and `knowledge_search` MCP tools. This wastes tokens on every message and confuses the agent when the tools aren't available.

## Context
- `providers/claude.md` is appended to `AGENTS.md` by `build.sh` to produce `~/.claude/CLAUDE.md`
- `AGENTS.md` is the shared global workflow (all agents read it)
- The Memory Checkpoints section in `AGENTS.md` has one line referencing knowledge graph
- After editing source files, run `./build.sh` to regenerate all provider configs
- `./check.sh` verifies byte-equality between source and generated files

## How

**Step 1 — Edit `providers/claude.md`:**
- File: `providers/claude.md`
- In the "Memory Location" section, remove:
  ```
  **Reading:** If `.project/knowledge.db` exists, use `knowledge_context`, `knowledge_search`,
  `knowledge_status` MCP tools — they index the same files. Fallback (no DB): read files directly.
  ```
- Replace with:
  ```
  **Reading:** Use `brief search` for lookups. Fallback: read `MEMORY.md` index + `memory/` files directly.
  ```

**Step 2 — Edit `AGENTS.md`:**
- File: `AGENTS.md`
- In the "Memory Checkpoints (Mandatory)" section (around line 96-98), find:
  ```
  Memory lives **in the repo as structured files** (`memory/`, `decisions/`, `context.md`, `retro.md`) —
  never in provider global config. Knowledge graph (`.project/knowledge.db`) is the primary read path
  when available; files are always the source of truth.
  ```
- Replace with:
  ```
  Memory lives **in the repo as structured files** (`memory/`, `decisions/`, `context.md`, `retro.md`) —
  never in provider global config. Use `brief search` for lookups; files are always the source of truth.
  ```

**Step 3 — Rebuild provider configs:**
```bash
cd ~/.agents && ./build.sh
```

**Step 4 — Verify:**
```bash
grep -n "knowledge" providers/claude.md AGENTS.md
# Expected: 0 results

./check.sh
# Expected: passes (generated files match source)
```

## Files to Read First
- `providers/claude.md` — Claude-specific appendix (lines 10-18 are the memory section)
- `AGENTS.md` — global workflow (lines 95-102 are Memory Checkpoints)
- `build.sh` — generates provider configs from these source files
