# S-005-T2: Update `brief init` — remove `.project/`, add `.claude/CLAUDE.md`

**Priority:** P0 | **Status:** pending | **Blocked By:** S-005-T1

## What
Modify `brief/lib/init.mjs` to stop creating the `.project/` directory and its gitignore, and to scaffold `.claude/CLAUDE.md` with the `@AGENTS.md` pointer pattern.

## Why
`brief init` currently creates `.project/` with a `.gitignore` for `knowledge.db` — a file that is never generated. New projects should instead get `.claude/CLAUDE.md` which completes the provider appendix pattern (Claude reads CLAUDE.md, which imports the shared AGENTS.md).

## Context
- `init.mjs` is at `brief/lib/init.mjs`
- It has a `DIRS` array and a `FILES` array that define what gets scaffolded
- It currently creates `.project/` and writes `.project/.gitignore` with `knowledge.db\n`
- The codegraph init (`.codegraph/`) is separate and stays untouched
- `.claude/CLAUDE.md` should use the `@AGENTS.md` import syntax (Claude Code expands this)
- Skip creating any file/dir that already exists (existing pattern in the code)

## How

**Step 1 — Remove `.project/` from DIRS:**
- File: `brief/lib/init.mjs`
- Line ~24: Remove `".project"` from the `DIRS` array

**Step 2 — Add `.claude` to DIRS:**
- Add `".claude"` to the DIRS array (needed for CLAUDE.md to land there)

**Step 3 — Add CLAUDE.md to FILES:**
- Add to the FILES array: `{ src: "CLAUDE.md", dest: ".claude/CLAUDE.md" }`
- This means we also need the template file

**Step 4 — Create the CLAUDE.md template:**
- File: `templates/project-structure/CLAUDE.md`
- Content:

```markdown
@AGENTS.md

<!--
Everything lives in AGENTS.md — commands, hard rules, and the documentation map.
The commit/push/PR approval gates are global now (WORKFLOW.md, and the
`/sdlc implement` skill), so they are in context without an import; AGENTS.md
keeps only what those gates mean in this repo.
Do not add rules here; add them to AGENTS.md.

Claude-specific instructions (things no other agent should read) go below.
-->
```

**Step 5 — Remove `.project/.gitignore` creation:**
- File: `brief/lib/init.mjs`
- Remove the block (approx lines 60-65):
```javascript
  // Create .gitignore for .project/ (knowledge.db is local-only)
  const gitignorePath = join(projectRoot, ".project/.gitignore");
  if (!existsSync(gitignorePath)) {
    writeFileSync(gitignorePath, "knowledge.db\n");
    created.push(".project/.gitignore");
  }
```

**Step 6 — Verify:**
```bash
cd /tmp && mkdir test-init && cd test-init && git init
brief init
ls -la .claude/CLAUDE.md   # should exist
ls -la .project/           # should NOT exist
cat .claude/CLAUDE.md      # should show @AGENTS.md
rm -rf /tmp/test-init
```

Also run existing tests:
```bash
cd ~/.agents/brief && npm test
```
