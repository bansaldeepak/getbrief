# S-012-T1: Fix BRIEF_SKILLS_PATH + update test

**Priority:** P0 | **Status:** pending | **Blocked By:** --

## What
Change `BRIEF_SKILLS_PATH` in `lib/init.mjs` from a `homedir()`-based path to a path resolved from `import.meta.url`. Update the test assertion in `test/init.test.mjs` that checks the symlink target.

## Why
The current path (`~/.agents/brief/skills/brief`) only exists on the original developer's machine. Every other machine gets broken symlinks after `brief init`. This is a one-line fix with immediate value.

## Context
`lib/init.mjs` line 11 already resolves `__dirname`:
```js
const __dirname = dirname(fileURLToPath(import.meta.url));
```

Line 15 currently hardcodes:
```js
const BRIEF_SKILLS_PATH = join(homedir(), ".agents", "brief", "skills", "brief");
```

The `skills/brief/` directory is at `../skills/brief/` relative to `lib/`. This path works on any machine where brief is installed.

`test/init.test.mjs` line 9 hardcodes the same broken path:
```js
const BRIEF_SKILLS_PATH = join(homedir(), ".agents", "brief", "skills", "brief");
```

And line 63 asserts the symlink target matches it:
```js
assert.equal(readlinkSync(linkPath), BRIEF_SKILLS_PATH);
```

Both must be updated to match the new resolution.

## How

**Step 1 — Fix init.mjs:15:**
- File: `lib/init.mjs`
- Change line 15 from:
  ```js
  const BRIEF_SKILLS_PATH = join(homedir(), ".agents", "brief", "skills", "brief");
  ```
  To:
  ```js
  const BRIEF_SKILLS_PATH = join(__dirname, "../skills/brief");
  ```

**Step 2 — Update test/init.test.mjs:**
- File: `test/init.test.mjs`
- Change line 9 from:
  ```js
  const BRIEF_SKILLS_PATH = join(homedir(), ".agents", "brief", "skills", "brief");
  ```
  To:
  ```js
  import { dirname } from "node:path";
  import { fileURLToPath } from "node:url";
  const __testDirname = dirname(fileURLToPath(import.meta.url));
  const BRIEF_SKILLS_PATH = join(__testDirname, "../skills/brief");
  ```
  Note: `dirname` and `fileURLToPath` may already be imported — check before adding duplicates. The `join` import already exists at line 4.

**Step 3 — Verify:**
```bash
node --test test/init.test.mjs
```
