# S-012-T7: Self-migrate this repo

**Priority:** P1 | **Status:** pending | **Blocked By:** S-012-T5, S-012-T6

## What
Run `brief init` in this repo to dogfood the new harness injection. Update `.claude/CLAUDE.md` to use the new `.brief/HARNESS.md` path. Delete the root `HARNESS.md` (content now lives in `templates/HARNESS.md`).

## Why
This repo currently has `@../HARNESS.md` in `.claude/CLAUDE.md` pointing to the root HARNESS.md. After moving the source content to `templates/HARNESS.md`, the root copy becomes stale. Running `brief init` dogfoods the feature and validates the full injection flow.

## Context
Current `.claude/CLAUDE.md` contains:
```markdown
@../HARNESS.md
```

After `brief init`, this repo should have:
- `.brief/HARNESS.md` — copied from `templates/HARNESS.md` (committed, not gitignored)
- `AGENTS.md` — with inline `<!-- brief:auto section="harness" -->` marker
- `.claude/CLAUDE.md` — with `@../AGENTS.md` (inherits harness via AGENTS.md import, matrix row 3 or row 1 depending on whether AGENTS.md already exists)

The root `HARNESS.md` should be deleted — its content moved to `templates/HARNESS.md` in T-003.

### Important edge case
This repo already has `.claude/CLAUDE.md` with `@../HARNESS.md` but may not have an `AGENTS.md`. Check the actual state before running init:
- If AGENTS.md doesn't exist: matrix row 1 (create both)
- If AGENTS.md exists: depends on whether CLAUDE.md imports it

After init, `.claude/CLAUDE.md` will either:
- Have `@../AGENTS.md` (if init created it fresh via row 1 or 2), OR
- Keep its existing content with a harness marker added (if row 3 or 4)

Either way, remove the old `@../HARNESS.md` line manually if init didn't replace it, and ensure `.claude/CLAUDE.md` correctly references the injected harness (either through AGENTS.md import or through its own marker).

## How

**Step 1 — Check current state:**
```bash
ls -la AGENTS.md .claude/CLAUDE.md .brief/HARNESS.md 2>&1
cat .claude/CLAUDE.md
```

**Step 2 — Run brief init:**
```bash
brief init
```
Answer "Y" to proceed.

**Step 3 — Verify injection:**
```bash
cat .brief/HARNESS.md
# Should contain trimmed harness content (~30 lines)

cat AGENTS.md
# Should contain <!-- brief:auto section="harness" --> marker with inline content

cat .claude/CLAUDE.md
# Should reference AGENTS.md (directly or via @../AGENTS.md)
```

**Step 4 — Clean up .claude/CLAUDE.md:**
If `.claude/CLAUDE.md` still has `@../HARNESS.md`, remove that line. The harness content now comes via the marker in AGENTS.md (which CLAUDE.md imports) or via `.brief/HARNESS.md` marker in CLAUDE.md itself.

Ensure `.claude/CLAUDE.md` has any project-specific content (like the Codex CLI login note) preserved.

**Step 5 — Delete root HARNESS.md:**
```bash
git rm HARNESS.md
```

**Step 6 — Verify full test suite:**
```bash
node --test
```
