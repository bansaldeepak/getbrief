# S-012-T2: Decouple Codex detection from AGENTS.md + update test

**Priority:** P0 | **Status:** pending | **Blocked By:** --

## What
Remove `AGENTS.md` from Codex detection in `lib/detect.mjs`. Update `test/detect.test.mjs` to flip the assertion for the AGENTS.md-only case.

## Why
`findAgentDirs()` currently treats AGENTS.md presence as a Codex indicator. But `brief init` now creates AGENTS.md (via harness injection) — which would falsely flag every initialized project as a Codex project on re-run. `.codex/` directory is the canonical Codex indicator.

## Context
`lib/detect.mjs` line 49 currently:
```js
codex: existsSync(join(projectRoot, ".codex")) || existsSync(join(projectRoot, "AGENTS.md")),
```

The `||` with AGENTS.md was a heuristic that made sense before brief created AGENTS.md. After T-004/T-005, brief creates AGENTS.md as part of harness injection, so the heuristic becomes wrong.

`test/detect.test.mjs` lines 37-41 assert the old behavior:
```js
it("detects AGENTS.md as codex indicator", () => {
    writeFileSync(join(tmp, "AGENTS.md"), "# Agents");
    const result = findAgentDirs(tmp);
    assert.equal(result.codex, true);
});
```

This test must flip to `codex: false`.

## How

**Step 1 — Fix detect.mjs:49:**
- File: `lib/detect.mjs`
- Change line 49 from:
  ```js
  codex: existsSync(join(projectRoot, ".codex")) || existsSync(join(projectRoot, "AGENTS.md")),
  ```
  To:
  ```js
  codex: existsSync(join(projectRoot, ".codex")),
  ```

**Step 2 — Update detect.test.mjs:37-41:**
- File: `test/detect.test.mjs`
- Change the test at lines 37-41:
  ```js
  it("does not detect AGENTS.md as codex indicator", () => {
      writeFileSync(join(tmp, "AGENTS.md"), "# Agents");
      const result = findAgentDirs(tmp);
      assert.equal(result.codex, false);
  });
  ```

- Also update line 62-68 (multi-agent test) — it currently expects `codex: true` when AGENTS.md exists. After this change, that test needs `.codex/` directory instead of or in addition to AGENTS.md:
  ```js
  it("detects multiple agents simultaneously", () => {
      mkdirSync(join(tmp, ".claude"));
      mkdirSync(join(tmp, ".codex"));
      mkdirSync(join(tmp, ".gemini"));
      const result = findAgentDirs(tmp);
      assert.deepEqual(result, { claude: true, codex: true, gemini: true });
  });
  ```

**Step 3 — Verify:**
```bash
node --test test/detect.test.mjs
```
