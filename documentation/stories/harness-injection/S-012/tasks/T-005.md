# S-012-T5: Wire harness into init.mjs

**Priority:** P0 | **Status:** pending | **Blocked By:** S-012-T1, S-012-T2, S-012-T4

## What
Integrate `detectHarnessState()` and `applyHarness()` from `lib/harness.mjs` into `lib/init.mjs`. Remove the old AGENTS.md creation gate (lines 52-64). Update `printSummary()` to include harness actions.

## Why
This wires the new harness module into the init flow. After this task, `brief init` actually injects HARNESS into projects.

## Context
The current init flow in `lib/init.mjs` (`initProject()` function, starting line 39):

1. `scaffoldDocs()` — dirs + template copies
2. `detectStack()` — tech stack detection
3. AGENTS.md creation gated on Codex detection (lines 52-64) — **REMOVE THIS**
3.5. *(new)* `detectHarnessState()` — before confirmation
4. `filterRelevantRules()` — rule matching
5. Interactive confirmation — `printSummary()` + `ask()` (lines 70-77)
5b. *(new)* `applyHarness()` — after confirmation
6-10. Symlinks, rules copy, manifest, gitignore, codegraph

The detect/apply split (eng review D1) matches the existing `filterRelevantRules` (step 4) + `copyRelevantRules` (step 8) pattern — detect before confirmation, apply after.

### Code to remove (lines 52-64):
```js
// Create AGENTS.md only if Codex detected
if (detection.agents.codex) {
    const agentsMdDest = join(projectRoot, "AGENTS.md");
    if (!existsSync(agentsMdDest)) {
        const agentsMdSrc = join(TEMPLATES_DIR, "AGENTS.md");
        if (existsSync(agentsMdSrc)) {
            copyFileSync(agentsMdSrc, agentsMdDest);
            created.push("AGENTS.md");
        }
    } else {
        skipped.push("AGENTS.md");
    }
}
```

This is replaced by `applyHarness()` which handles AGENTS.md creation as part of the injection matrix.


**Step 2 — Remove AGENTS.md gate (lines 52-64):**
- Delete the entire `if (detection.agents.codex) { ... }` block.

**Step 3 — Add detectHarnessState call at step 3.5:**
- After `const detection = detectStack(projectRoot);` (line 50), add:
  ```js
  // 3.5. Detect harness injection state (before confirmation)
  let harnessState = null;
  try {
    harnessState = detectHarnessState(projectRoot);
  } catch (err) {
    console.warn(`Warning: harness detection failed: ${err.message}`);
  }
  ```

**Step 4 — Update printSummary to include harness actions:**
- Modify `printSummary()` (starts at line 316) to accept and display harness state:
  ```js
  function printSummary(projectRoot, detection, relevantRules, harnessState) {

  }
  ```
- Update the `printSummary` call (line 71) to pass `harnessState`:
  ```js

  ```

**Step 5 — Add applyHarness call after confirmation:**
- After the confirmation block (after line 77), add:
  ```js
  // 5b. Apply harness injection (after confirmation)
  if (harnessState) {
    try {
      const harnessResult = applyHarness(projectRoot, harnessState);
      created.push(...harnessResult.copied, ...harnessResult.injected);

      console.warn(`Warning: harness injection failed: ${err.message}`);
  ```
