# S-010-T2: Enhance init.mjs to Copy All Templates

**Priority:** P0 | **Status:** completed | **Blocked By:** S-010-T1

## What

Modify `brief/lib/init.mjs` to copy ALL rule template skeletons from `brief/templates/rules/` into the project's `.claude/rules/` directory during `brief init`. No detection, no interactive selection — just copy everything (D9 decision).

## Why

Users get a complete set of rule templates on init. They delete what they don't need. This is simpler than interactive selection (which is deferred to `/brief setup` in Epic 1) and ensures every project starts with guidance available.

## Context

**Current init.mjs behavior (from brief/test/init.test.mjs):**
1. Creates `documentation/` directory structure
2. Sets up codegraph (code-index)
3. Creates `.claude/CLAUDE.md` scaffold

**New behavior to ADD (not replace):**
4. Read `brief/templates/rules/manifest.json` to get list of template files
5. Create `.claude/rules/` directory if it doesn't exist
6. Copy each template file from `brief/templates/rules/<file>` to `.claude/rules/<file>`
7. Skip any file that already exists (don't overwrite user customizations)
8. Print summary of what was copied

**Design Decision D9:** Init copies ALL templates without detection or selection. User deletes unwanted ones. Smart selection deferred to Epic 1.

**Key implementation detail:** The templates directory is relative to the brief package installation, NOT relative to the project. Use `import.meta.url` or `__dirname` equivalent to resolve the template path.

```javascript
import { fileURLToPath } from "node:url";
import { dirname } from "node:path";
const __dirname = dirname(fileURLToPath(import.meta.url));
const TEMPLATES_DIR = join(__dirname, "../templates/rules");
```

## How

**Step 1 — Read current init.mjs:**
- File: `brief/lib/init.mjs`
- Understand the current flow and where to add template copying

**Step 2 — Add template copying function:**
- File: `brief/lib/init.mjs`
- Add after existing initialization steps:

```javascript
import { fileURLToPath } from "node:url";

function copyRuleTemplates(projectRoot) {
  const __dir = dirname(fileURLToPath(import.meta.url));
  const templatesDir = join(__dir, "../templates/rules");
  const manifestPath = join(templatesDir, "manifest.json");

  if (!existsSync(manifestPath)) {
    return; // No templates available (shouldn't happen in normal install)
  }

  const manifest = JSON.parse(readFileSync(manifestPath, "utf8"));
  const rulesDir = join(projectRoot, ".claude", "rules");
  mkdirSync(rulesDir, { recursive: true });

  let copied = 0;
  let skipped = 0;

  for (const template of manifest.templates) {
    const src = join(templatesDir, template.file);
    const dest = join(rulesDir, template.file);

    if (existsSync(dest)) {
      skipped++;
      continue;
    }

    if (existsSync(src)) {
      copyFileSync(src, dest);
      copied++;
    }
  }

  if (copied > 0) {
    console.log(`  ✓ Copied ${copied} rule template(s) to .claude/rules/`);
  }
  if (skipped > 0) {
    console.log(`  ⊘ Skipped ${skipped} (already exist)`);
  }
}
```

**Step 3 — Call the function in init flow:**
- Add `copyRuleTemplates(projectRoot)` after the existing init steps
- Import `copyFileSync` from `node:fs` (add to existing import)

**Step 4 — Also ensure .claude/CLAUDE.md references local rules:**
- If init already creates `.claude/CLAUDE.md`, add a comment/section noting local rules exist:
```markdown
## Local Rules

Project-specific rules live in `.claude/rules/`. Edit the skeleton files to match this project's conventions. Delete templates you don't need.
```
