# S-010-T3: Write Tests for Init Template Copying

**Priority:** P1 | **Status:** completed | **Blocked By:** S-010-T2

## What

Extend `brief/test/init.test.mjs` with tests that verify the template-copying behavior added in T2: copies all templates, skips existing files, handles missing manifest gracefully.

## Why

Init is the entry point for new projects. If template copying breaks (wrong paths, overwriting user files, crashing on missing manifest), it degrades the first-run experience. Tests prevent regressions as the init flow evolves.

## Context

**Existing init.test.mjs (58 lines):** Tests directory creation and codegraph setup. Uses temp directories and assertions.

**New behavior to test (from T2):**
1. After init, `.claude/rules/` contains all 6 template files
2. Running init again doesn't overwrite modified files
3. If manifest.json is missing, init still succeeds (graceful skip)
4. Template content matches source files

**Test infrastructure:**
- Runner: `node:test`
- Assertions: `node:assert/strict`
- Pattern: `mkdtempSync` → run init → assert filesystem state → `rmSync`

**Step 2 — Add template-copying tests:**
- File: `brief/test/init.test.mjs`
- Add a new `describe("rule templates", ...)` block:

```javascript
describe("rule templates", () => {
  test("init copies all template files to .claude/rules/", async () => {
    // Run init on temp directory
    // Assert: .claude/rules/ exists
    // Assert: all 6 template files present
    const expectedFiles = [
      "backend-standards.md",
      "frontend-standards.md",
      "coding-style.md",
      "deployment.md",
      "observability-wiring.md",
      "git-workflow.md",
    ];
    for (const file of expectedFiles) {
      assert.ok(
        existsSync(join(root, ".claude/rules", file)),
        `Expected ${file} to be copied`
      );
    }
  });

  test("init does not overwrite existing rule files", async () => {
    // Create .claude/rules/coding-style.md with custom content BEFORE init
    mkdirSync(join(root, ".claude/rules"), { recursive: true });
    writeFileSync(join(root, ".claude/rules/coding-style.md"), "# My custom rules\n");

    // Run init
    // Assert: coding-style.md still has custom content
    const content = readFileSync(join(root, ".claude/rules/coding-style.md"), "utf8");
    assert.equal(content, "# My custom rules\n");

    // Assert: other templates were still copied
    assert.ok(existsSync(join(root, ".claude/rules/backend-standards.md")));
  });

  test("template content has valid frontmatter", async () => {
    // Run init
    // Read any copied template
    const content = readFileSync(join(root, ".claude/rules/backend-standards.md"), "utf8");
    // Assert: starts with ---
    assert.ok(content.startsWith("---"));
    // Assert: has description field
    assert.match(content, /description:/);
  });
});
```
