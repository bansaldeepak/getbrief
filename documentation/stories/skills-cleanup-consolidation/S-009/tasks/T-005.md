# S-009-T5: Delete Pre-Mortem Skill

**Priority:** P1 | **Status:** pending | **Blocked By:** S-009-T1

## What

Hard-delete the `custom-skills/pre-mortem/` directory and its symlink in `~/.claude/skills/`. The pre-mortem's risk assessment functionality has been absorbed into `sdlc/bug` (T1).

## Why

The pre-mortem skill (96 lines) is now redundant — its key elements (auto-trigger criteria, risk prompt, 4 angles, categorization) live in sdlc/bug/SKILL.md. Keeping both means agents might invoke the standalone pre-mortem instead of the integrated bug workflow, creating confusion about which to use.

## Context

**Pre-mortem skill location:**
- Source: `~/.agents/custom-skills/pre-mortem/SKILL.md` (96 lines)
- Symlink: `~/.claude/skills/pre-mortem` → `~/.agents/custom-skills/pre-mortem`

**What was absorbed into sdlc/bug (T1):**
- Auto-trigger criteria (db, auth, external, payment) ✓
- "Imagine failure" risk prompt ✓
- 4 risk angles (Technical, Product, Process, External) ✓
- Simplified categorization (blocks-fix / acceptable) ✓

**What was intentionally NOT absorbed (dropped):**
- Paper Tigers / Elephants framework (overkill for bugs)
- Classification tiers (Launch-blocking / Fast-follow / Track)
- Owner assignment (single developer workflow)
- Full output format template

**Reference in AGENTS.md:** Line 19 says "Off-graph: `/sdlc decision-doc` for any non-obvious choice, `/pre-mortem` before high-risk work." This reference must be updated to reflect the new location.

**Safety check:** Grep for any other references before deleting.

## How

**Step 1 — Grep for pre-mortem references:**
```bash
grep -r "pre-mortem\|pre_mortem\|premortem" ~/.claude/ ~/.agents/ --include="*.md" --include="*.mjs" -l 2>/dev/null | grep -v "node_modules\|/stories/"
```
Expected results:
- `AGENTS.md` (line 19) — must update
- `custom-skills/pre-mortem/` — being deleted
- `~/.claude/skills/pre-mortem` — symlink being deleted
- Possibly the TRD/PRD (in stories folder — excluded by grep filter, fine to leave as historical reference)

**Step 2 — Update AGENTS.md reference:**
- File: `AGENTS.md`
- Change line 19 from:
  ```
  Off-graph: `/sdlc decision-doc` for any non-obvious choice, `/pre-mortem` before high-risk work.
  ```
- To:
  ```
  Off-graph: `/sdlc decision-doc` for any non-obvious choice, `/sdlc bug` for bugs (includes risk assessment).
  ```

**Step 3 — Delete the skill:**
```bash
rm -rf custom-skills/pre-mortem
rm -f ~/.claude/skills/pre-mortem
```

**Step 4 — Verify:**
```bash
# Confirm deleted
ls custom-skills/pre-mortem 2>&1
# Should error: No such file or directory
ls ~/.claude/skills/pre-mortem 2>&1
# Should error: No such file or directory

# Confirm no dangling references (outside stories/)
grep -r "pre-mortem" ~/.claude/ ~/.agents/ --include="*.md" --include="*.mjs" 2>/dev/null | grep -v "node_modules\|/stories/"
# Should return nothing (or only the updated AGENTS.md line with "sdlc bug")

# Remaining custom-skills
ls custom-skills/
# Should show: brief, project-memory, sdlc (pre-mortem gone)
```
