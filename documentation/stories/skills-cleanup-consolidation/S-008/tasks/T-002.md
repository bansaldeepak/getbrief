# S-008-T2: Implement bug.mjs + Register + Tests

**Priority:** P0 | **Status:** completed | **Blocked By:** S-008-T1

## What

Create `brief/lib/commands/bug.mjs` as a thin delegation layer over item.mjs with type='bug', register it in the CLI router, add TYPE_CONFIG entry, and write tests.

## Why

`brief bug create/list/show/update` is the CLI foundation for the bug workflow (R6 in PRD). The sdlc/bug subskill (Story D) depends on this command existing. It must work identically to `brief todo` but with bug-specific fields (severity, priority).

## Context

**Design decision (D2 from TRD):** Bug and memory commands delegate to item.mjs — they are thin type-specific layers, NOT standalone implementations.

**What "thin delegation" means:**
- bug.mjs does NOT implement CRUD itself
- It adds `bug` to TYPE_CONFIG (tracker.mjs) and FILE_DIRS (item.mjs)
- It provides a bug-specific TEMPLATE
- It delegates to `itemCommand(root, "bug", action, args, rawArgs)`

**Tracker schema for bugs (from TRD):**
```yaml
- id: BUG-001
  type: bug
  title: "Description of the bug"
  status: open | in_progress | done
  priority: P1 | P2 | P3
  severity: critical | major | minor
  created: 2026-08-22
  story: null
  escalated_to: null  # S-NNN if bug grew into story
```

**CLI router (brief/cli.mjs line 129):**
```javascript
} else if (["todo", "decision", "research", "audit"].includes(command)) {
```

**Step 5 — Write bug.test.mjs:**
- File: `brief/test/bug.test.mjs`
```javascript
import { test, describe, beforeEach, afterEach } from "node:test";
import assert from "node:assert/strict";
import { mkdtempSync, mkdirSync, writeFileSync, readFileSync, existsSync, rmSync } from "node:fs";
import { join } from "node:path";
import { tmpdir } from "node:os";
import { itemCommand } from "../lib/commands/item.mjs";

describe("brief bug", () => {
  let root;

  beforeEach(() => {
    root = mkdtempSync(join(tmpdir(), "brief-bug-test-"));
    mkdirSync(join(root, "documentation"), { recursive: true });
    writeFileSync(join(root, "documentation/tracker.yaml"), "items: []\n");
  });

  afterEach(() => {
    rmSync(root, { recursive: true, force: true });
  });

  test("creates bug with BUG- prefix", async () => {
    await itemCommand(root, "bug", "create", ["Login fails on Safari"], []);
    const tracker = readFileSync(join(root, "documentation/tracker.yaml"), "utf8");
    assert.match(tracker, /BUG-001/);
    assert.match(tracker, /type: bug/);
  });

  test("creates bug file in documentation/bugs/", async () => {
    await itemCommand(root, "bug", "create", ["API timeout"], []);
    assert.ok(existsSync(join(root, "documentation/bugs/BUG-001.md")));
  });

  test("bug template includes severity field", async () => {
    await itemCommand(root, "bug", "create", ["Crash on load"], []);
    const content = readFileSync(join(root, "documentation/bugs/BUG-001.md"), "utf8");
    assert.match(content, /severity: major/);
    assert.match(content, /escalated_to: null/);
  });

  test("update bug status", async () => {
    await itemCommand(root, "bug", "create", ["Fix this"], []);
    await itemCommand(root, "bug", "update", ["BUG-001", "status=done"], []);
    const tracker = readFileSync(join(root, "documentation/tracker.yaml"), "utf8");
    assert.match(tracker, /status: done/);
  });
});
```
