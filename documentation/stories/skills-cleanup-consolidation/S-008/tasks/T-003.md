# S-008-T3: Implement memory.mjs + Register + Tests

**Priority:** P0 | **Status:** pending | **Blocked By:** S-008-T1

## What

Create `brief/lib/commands/memory.mjs` as a thin delegation layer over item.mjs with type='memory', register it in the CLI router, add TYPE_CONFIG entry, and write tests.

## Why

`brief memory create/list/show/update` provides first-class memory CRUD via CLI (R7 in PRD). Currently, memory files are created manually. This command integrates memory management into the same workflow as todos, stories, and bugs.

## Context

**Design decision (D2 from TRD):** Memory commands delegate to item.mjs — thin type-specific layer, NOT a standalone implementation.

**Memory file format (from TRD, matches existing memory files):**
```yaml
---
name: <slug>
description: <one-line>
type: <project|reference|feedback|user>
created: <date>
updated: <date>
valid_until: <date|permanent>
importance: <1-5>
---

<body content>
```

Note: The `type` field in memory frontmatter is the memory *category* (project/reference/feedback/user), NOT the tracker type. The tracker type is `memory`. Don't confuse these.

**What needs changing (same pattern as T2/bug.mjs):**
1. Add `memory` to TYPE_CONFIG in tracker.mjs
2. Add memory template and FILE_DIRS entry in item.mjs
3. Add `"memory"` to CLI router array in cli.mjs (T2 already added "bug", now add "memory")

**Memory directory:** `documentation/memory/` (already exists in projects with brief initialized)

## How

**Step 1 — Add memory to TYPE_CONFIG in tracker.mjs:**
- File: `brief/lib/tracker.mjs`
- Add to TYPE_CONFIG object:
```javascript
memory: { prefix: "MEM", defaultStatus: "active", hasPriority: false },
```

**Step 2 — Add memory template and FILE_DIRS entry in item.mjs:**
- File: `brief/lib/commands/item.mjs`
- Add to `FILE_DIRS`:
```javascript
memory: "documentation/memory",
```
- Add to `TEMPLATES`:
```javascript
memory: (id, title, opts, today) => `---
name: ${title.toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/(^-|-$)/g, "")}
description: ${title}
metadata:
  type: ${opts.memtype || "project"}
created: ${today}
updated: ${today}
valid_until: ${opts.valid_until || "permanent"}
importance: ${opts.importance || "3"}
---

${title}
`,
```

Note: Memory files use `name` slug as filename (not MEM-001). But the tracker still assigns MEM-001 for internal tracking. The actual file is named by slug: `documentation/memory/<slug>.md`.

**Step 3 — Handle memory filename override:**
- File: `brief/lib/commands/item.mjs`
- In `itemCreate` function, after generating the file path, add a special case for memory type to use the slug as filename instead of ID:
```javascript
// In itemCreate, around line 238-242:
const slug = title.toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/(^-|-$)/g, "");
const fileName = type === "memory" ? `${slug}.md` : `${id}.md`;
```

**Step 4 — Register in CLI router:**
- File: `brief/cli.mjs`
- Change the array (which T2 already modified to include "bug"):
```javascript
} else if (["todo", "decision", "research", "audit", "bug", "memory"].includes(command)) {
```

**Step 5 — Add memory to help text:**
- File: `brief/cli.mjs`
- Add after the bug help line:
```
  memory <action>       Manage memory entries (create, list, show, update)
```

**Step 6 — Write memory.test.mjs:**
- File: `brief/test/memory.test.mjs`
```javascript
import { test, describe, beforeEach, afterEach } from "node:test";
import assert from "node:assert/strict";
import { mkdtempSync, mkdirSync, writeFileSync, readFileSync, existsSync, rmSync, readdirSync } from "node:fs";
import { join } from "node:path";
import { tmpdir } from "node:os";
import { itemCommand } from "../lib/commands/item.mjs";

describe("brief memory", () => {
  let root;

  beforeEach(() => {
    root = mkdtempSync(join(tmpdir(), "brief-memory-test-"));
    mkdirSync(join(root, "documentation"), { recursive: true });
    writeFileSync(join(root, "documentation/tracker.yaml"), "items: []\n");
  });

  afterEach(() => {
    rmSync(root, { recursive: true, force: true });
  });

  test("creates memory with MEM- prefix in tracker", async () => {
    await itemCommand(root, "memory", "create", ["API rate limits"], []);
    const tracker = readFileSync(join(root, "documentation/tracker.yaml"), "utf8");
    assert.match(tracker, /MEM-001/);
    assert.match(tracker, /type: memory/);
  });

  test("creates memory file with slug name", async () => {
    await itemCommand(root, "memory", "create", ["API rate limits"], []);
    assert.ok(existsSync(join(root, "documentation/memory/api-rate-limits.md")));
  });

  test("memory template includes metadata type", async () => {
    await itemCommand(root, "memory", "create", ["Deploy process"], []);
    const files = readdirSync(join(root, "documentation/memory"));
    const content = readFileSync(join(root, "documentation/memory", files[0]), "utf8");
    assert.match(content, /type: project/);
    assert.match(content, /valid_until: permanent/);
  });

  test("update memory status", async () => {
    await itemCommand(root, "memory", "create", ["Old info"], []);
    await itemCommand(root, "memory", "update", ["MEM-001", "status=stale"], []);
    const tracker = readFileSync(join(root, "documentation/tracker.yaml"), "utf8");
    assert.match(tracker, /status: stale/);
  });
});
```
