# S-008-T4: Update rules/brief.md with New Commands

**Priority:** P1 | **Status:** pending | **Blocked By:** S-008-T2, S-008-T3

## What

Update the `rules/brief.md` file to document the new `brief bug` and `brief memory` commands in the Quick Reference section.

## Why

`rules/brief.md` is loaded every session when documentation files are touched. Agents use it to know what brief commands are available. Without documentation, agents won't know about or use the new bug/memory commands.

## Context

**Current rules/brief.md (112 lines):** Contains Quick Reference with all brief commands, Code + Doc Search section, Graduated Context section, and usage guidance.

**The Quick Reference section has commands grouped by category.** New commands should follow the existing style:
```bash
# Create (--body for full content, or omit for template)
brief story create "Feature name" --body="## Context\n..."
```

## How

**Step 1 — Add bug commands to rules/brief.md Quick Reference:**
- File: `rules/brief.md`
- Add after the existing `brief todo` section (or in a logical position):
```bash
# Bug tracking
brief bug create "Bug description" --body="## Steps to Reproduce\n..."
brief bug list                      # open bugs
brief bug show BUG-001              # full bug file
brief bug update BUG-001 status=done "note=Fixed in commit abc123"
brief bug update BUG-001 severity=critical
```

**Step 2 — Add memory commands:**
```bash
# Memory management
brief memory create "Key insight" --body="Details about the insight"
brief memory list                   # active memories
brief memory show MEM-001           # full memory file
brief memory update MEM-001 status=stale
```

**Step 3 — Update the "By type" section if it exists in status output:**
- The brief status command shows counts by type. No code change needed — it reads from tracker.yaml dynamically.

**Step 4 — Verify:**
```bash
grep -c "brief bug" rules/brief.md
# Should be ≥ 4
grep -c "brief memory" rules/brief.md
# Should be ≥ 4
```

## Files to Read First
- `rules/brief.md` — the file being modified (full content)
