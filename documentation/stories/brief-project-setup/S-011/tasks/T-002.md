# S-011-T2: detect.mjs — Agent Directory + Tech Stack Detection

**Priority:** P0 | **Status:** pending | **Blocked By:** --

## What
Create `~/.agents/brief/lib/detect.mjs` with two pure functions: `findAgentDirs(projectRoot)` for agent directory detection, and `detectStack(projectRoot)` for tech stack detection. Both return structured data; neither creates directories or modifies the filesystem.

## Why
The rewritten init needs to know which agents are present (to decide where to create symlinks) and what tech stack the project uses (to decide which rules are relevant). These are pure detection functions — detect-and-report, never create-and-act. Separating detection from action makes both testable and reusable by `brief doctor` and `/brief init` later.

## Context
**Agent detection** checks for directories that indicate an agent is configured:
- `.claude/` → Claude Code is used
- `.codex/` or `AGENTS.md` at root → Codex is used
- `.gemini/` or `.agents/rules/` → Gemini is used

**Tech stack detection** uses two layers:
1. **codegraph** (if initialized): `codegraph status --json <root>` returns `{"languages": [...]}`. Its output is JSON but can be malformed (SyntaxError must be caught).
2. **Manifest file reads**: Parse `package.json`, `Cargo.toml`, `go.mod`, `pyproject.toml`, `Gemfile` to extract frameworks, testing tools, and runtime.

**Existing code in brief:**
- `~/.agents/brief/templates/rules/manifest.json` has 7 detect patterns like `"package.json:express|fastify|hono|koa"` — these can be reused for tech detection
- The brief package uses ESM (`import`/`export`), Node.js 18+

**Output type — `DetectionResult`:**
```javascript
{
  languages: ["typescript", "javascript"],  // from codegraph or file extensions
  frameworks: ["hono", "prisma"],           // from manifest deps
  testing: ["vitest"],                      // from devDependencies
  runtime: "node",                          // node | deno | bun | python | go | rust
  hasCI: true,                              // .github/workflows/ or .gitlab-ci.yml exists
  agents: { claude: true, codex: false, gemini: false }
}
```

## How

**Step 1 -- Create the file:**
- File: `~/.agents/brief/lib/detect.mjs`

```javascript
import { existsSync, readFileSync, readdirSync } from "node:fs";
import { join } from "node:path";
import { execFileSync } from "node:child_process";

export function findAgentDirs(projectRoot) {
  return {
    claude: existsSync(join(projectRoot, ".claude")) && isDir(join(projectRoot, ".claude")),
    codex: existsSync(join(projectRoot, ".codex")) || existsSync(join(projectRoot, "AGENTS.md")),
    gemini: existsSync(join(projectRoot, ".gemini")) || existsSync(join(projectRoot, ".agents", "rules")),
  };
}

export function detectStack(projectRoot) {
  const result = {
    languages: [],
    frameworks: [],
    testing: [],
    runtime: null,
    hasCI: false,
    agents: findAgentDirs(projectRoot),
  };

  // Layer 1: Languages via codegraph (best-effort)
  result.languages = detectLanguages(projectRoot);

  // Layer 2: Frameworks + testing via manifest reads
  const deps = readManifestDeps(projectRoot);
  result.frameworks = deps.frameworks;
  result.testing = deps.testing;
  result.runtime = inferRuntime(projectRoot);
  result.hasCI = existsSync(join(projectRoot, ".github", "workflows"))
    || existsSync(join(projectRoot, ".gitlab-ci.yml"));

  return result;
}
```

**Step 2 -- Implement helper functions:**

`detectLanguages(projectRoot)`:
- Try `codegraph status --json <projectRoot>`. Wrap in try/catch for both exec errors AND JSON.parse SyntaxError.
- Fallback: scan root for common file extensions (`.ts`, `.js`, `.py`, `.go`, `.rs`, `.rb`) and deduce languages.

`readManifestDeps(projectRoot)`:
- Read `package.json` → extract `dependencies` + `devDependencies` keys
- Match against known framework names: hono, express, fastify, react, vue, next, prisma, drizzle
- Match testing: vitest, jest, mocha, playwright, cypress
- Also check: `Cargo.toml` (actix, tokio, serde), `go.mod` (gin, echo, fiber), `pyproject.toml` (django, flask, fastapi), `Gemfile` (rails, sinatra)

`inferRuntime(projectRoot)`:
- `package.json` exists → check for `"type": "module"` and engines → `"node"`
- `deno.json` exists → `"deno"`
- `bun.lockb` exists → `"bun"`
- `pyproject.toml` or `requirements.txt` → `"python"`
- `go.mod` → `"go"`
- `Cargo.toml` → `"rust"`
- Fallback: `null`

`isDir(path)`:
- `statSync(path).isDirectory()` wrapped in try/catch returning false
