# S-011-T3: symlink.mjs — Cross-Platform Symlink Utilities

**Priority:** P0 | **Status:** pending | **Blocked By:** S-011-T1

## What
Create `~/.agents/brief/lib/symlink.mjs` with utility functions for creating, verifying, and managing symlinks across platforms. Includes copy fallback for environments where symlinks are unavailable (Windows without dev mode, some Docker setups).

## Why
The rewritten init needs to create symlinks from project directories (`.claude/skills/brief`, `.agents/skills/brief`) to the brief package (`~/.agents/brief/skills/brief/`). This crosses filesystem boundaries (home → project), needs platform awareness, and must handle existing/broken/stale symlinks gracefully. Centralizing this logic makes it testable and reusable by both init and doctor.

## Context
**Symlink strategy (from TRD):**
- Single-level: project dir → brief package directly (no intermediate canonical layer)
- Absolute paths when crossing home→project boundary (relative would be fragile)
- EPERM on symlink creation → fall back to recursive copy with warning
- EEXIST → verify target matches; if wrong target, remove and re-create
- Must be idempotent: calling createLink twice with same args = no-op

**Where symlinks are created by init:**
```
PROJECT/.claude/skills/brief  →  ~/.agents/brief/skills/brief/
PROJECT/.agents/skills/brief  →  ~/.agents/brief/skills/brief/
```

**The brief package path** is `~/.agents/brief/skills/brief/`. The actual expanded home path is `/Users/db/.agents/brief/skills/brief/` on this machine, but the code should use `os.homedir()` for portability.

## How

**Step 1 -- Create the file:**
- File: `~/.agents/brief/lib/symlink.mjs`

```javascript
import { symlinkSync, readlinkSync, lstatSync, existsSync, cpSync, rmSync, mkdirSync } from "node:fs";
import { dirname, resolve } from "node:path";
import { homedir } from "node:os";

export function createLink(target, linkPath) {
  const resolvedTarget = target.replace(/^~/, homedir());
  mkdirSync(dirname(linkPath), { recursive: true });

  // Check if link already exists
  if (lstatExists(linkPath)) {
    const existing = safeReadlink(linkPath);
    if (existing === resolvedTarget) {
      return { status: "exists", mode: "symlink" };
    }
    // Wrong target — remove and re-create
    rmSync(linkPath, { recursive: true });
  }

  try {
    symlinkSync(resolvedTarget, linkPath);
    return { status: "created", mode: "symlink" };
  } catch (err) {
    if (err.code === "EPERM" || err.code === "EACCES") {
      return fallbackCopy(resolvedTarget, linkPath);
    }
    throw err;
  }
}

export function verifyLink(linkPath, expectedTarget) {
  const resolvedExpected = expectedTarget.replace(/^~/, homedir());
  if (!lstatExists(linkPath)) {
    return { valid: false, reason: "missing" };
  }
  const stat = lstatSync(linkPath);
  if (!stat.isSymbolicLink()) {
    return { valid: false, reason: "not-symlink" };
  }
  const actual = readlinkSync(linkPath);
  if (actual !== resolvedExpected) {
    return { valid: false, reason: "wrong-target", actual, expected: resolvedExpected };
  }
  // Check target actually exists
  if (!existsSync(linkPath)) {
    return { valid: false, reason: "broken", target: actual };
  }
  return { valid: true };
}

export function fallbackCopy(source, dest) {
  mkdirSync(dirname(dest), { recursive: true });
  cpSync(source, dest, { recursive: true });
  return { status: "created", mode: "copy", warning: "Symlinks unavailable, using copy mode. Updates won't auto-propagate." };
}

export function removeStale(linkPath) {
  if (!lstatExists(linkPath)) return false;
  const stat = lstatSync(linkPath);
  if (stat.isSymbolicLink() && !existsSync(linkPath)) {
    rmSync(linkPath);
    return true;
  }
  return false;
}
```

**Step 2 -- Add helper `lstatExists` and `safeReadlink`:**
```javascript
function lstatExists(p) {
  try { lstatSync(p); return true; } catch { return false; }
}

function safeReadlink(p) {
  try { return readlinkSync(p); } catch { return null; }
}
```

**Step 3 -- Write unit tests:**
- File: `~/.agents/brief/test/symlink.test.mjs`
- Uses `node:test` + `node:fs` with temp directories (`mkdtempSync`)
- Test cases:
  - `createLink` with non-existent link → creates symlink, returns `{status: "created", mode: "symlink"}`
  - `createLink` with already-correct symlink → returns `{status: "exists", mode: "symlink"}`
  - `createLink` with wrong-target symlink → removes old, creates new
  - `createLink` parent dir doesn't exist → creates parent dirs
  - `verifyLink` on valid symlink → `{valid: true}`
  - `verifyLink` on missing path → `{valid: false, reason: "missing"}`
  - `verifyLink` on regular file (not symlink) → `{valid: false, reason: "not-symlink"}`
  - `verifyLink` on broken symlink → `{valid: false, reason: "broken"}`
  - `verifyLink` on wrong-target → `{valid: false, reason: "wrong-target", actual, expected}`
  - `removeStale` on broken symlink → removes it, returns true
  - `removeStale` on valid symlink → leaves it, returns false
  - `removeStale` on non-existent path → returns false
  - `fallbackCopy` copies directory recursively
