# S-011-T4: Rewrite init.mjs — Full Interactive Installer

**Priority:** P0 | **Status:** completed | **Blocked By:** S-011-T2, S-011-T3

## What
Rewrite `~/.agents/brief/lib/init.mjs` to orchestrate the full init flow: scaffold documentation → detect agents + tech stack → interactive prompt → create symlinks → copy relevant rule templates → write manifest → update .gitignore. Support `--non-interactive` flag for CI/scripts.

## Why
Current init (148 lines) only scaffolds docs + copies rule templates + runs codegraph. It has no symlink creation, no agent detection, no interactive confirmation, no manifest tracking, and isn't idempotent. The rewrite makes `brief init` the single command that sets up the full agent ecosystem for a project.

## Context
**Current init.mjs** does (in order):
1. Create 8 directories under `documentation/`
2. Copy 5 scaffold files from `~/.agents/templates/project-structure/`
3. Read `manifest.json`, copy ALL matching rule templates to `.claude/rules/` (not idempotent — skips if file exists)
4. Run `codegraph init` (120s timeout, non-critical)
5. Add `.codegraph/` to `.gitignore`

**New init.mjs** does (in order):
1. Scaffold documentation dirs + files (same as current, keep this)
2. Call `detectStack(projectRoot)` → get detection result
3. Call `findAgentDirs(projectRoot)` → know which agents present
4. **If interactive (default)**: present summary + prompt for confirmation
5. Create symlinks: for each detected agent, link their skills dir to `~/.agents/brief/skills/brief/`
6. Copy relevant rule templates (filtered by detection, not copy-all)
7. Call `rules-gen` to place formatted skeletons per agent (T5 dependency — call if available, skip gracefully if not)
8. Write `.agents/brief-manifest.json` with full detection + symlink state
9. Update `.gitignore` with: `.agents/skills/`, `.claude/skills/`, `.agents/brief-manifest.json`, `.codegraph/`
10. Run codegraph init (same as current, non-critical)
11. Print summary

**Interactive prompt flow (readline-based):**
```
brief init
──────────────────────────────────────────────────
Project: /Users/dev/my-app
Detected: Node.js (Hono v4, Prisma)
Agents:   Claude (.claude/ found)

Skills to install:
  brief/      (lifecycle, project management, memory)

Rules to install (based on detected stack):
  ✓ coding-style.md         (always)
  ✓ backend-standards.md    (hono detected)
  ✗ frontend-standards.md   (no frontend detected)

Proceed? [Y/n] _
──────────────────────────────────────────────────
```

**`--non-interactive` behavior:** Skip all prompts, accept all detected defaults. Suitable for CI or scripted setups.

**Manifest schema (written at end):**
```json
{
  "version": "1.0.0",
  "installed_at": "2026-08-25T10:00:00Z",
  "mode": "symlink",
  "detection": {
    "languages": ["typescript", "javascript"],
    "frameworks": ["hono", "prisma"],
    "testing": ["vitest"],
    "runtime": "node",
    "agents": { "claude": true, "codex": false, "gemini": false }
  },
  "symlinks": [
    { "source": ".claude/skills/brief", "target": "~/.agents/brief/skills/brief", "status": "ok" },
    { "source": ".agents/skills/brief", "target": "~/.agents/brief/skills/brief", "status": "ok" }
  ],
  "rules_installed": ["coding-style.md", "backend-standards.md"]

```

**Idempotency contract:**
- Dirs already exist → skip
- Files already exist → skip
- Symlinks already correct → skip (verifyLink)
- Symlinks wrong target → remove + re-create
- Manifest always rewritten (reflects current state)
- Second run with no changes: only manifest timestamp updates

**Prompt decision tree (6 steps):**
1. Show detection summary (always, no prompt)
2. Confirm agents (if >1 detected): "Install skills for: [Claude, Codex]? [Y/n]" — default Y
3. Select rules (if >0 relevant): "Install these rules? [Y/n per item]" — toggling items
4. Confirm proceed: "Proceed? [Y/n]" — default Y
5. Abort behavior: "n" at step 4 exits clean. "n" at steps 2/3 skips that item.
6. Ctrl-C: Clean exit, no partial state (files written only after final Y)

## How

**Step 1 -- Refactor existing init to preserve scaffold logic:**
Keep the `DIRS` and `FILES` arrays + creation logic from current init.mjs. Extract into a `scaffoldDocs(projectRoot)` function.

**Step 2 -- Add interactive prompt module:**
Use Node.js built-in `readline` (zero deps). Create a helper:
```javascript
import { createInterface } from "node:readline";

function ask(question, defaultAnswer = "Y") {
  const rl = createInterface({ input: process.stdin, output: process.stdout });
  return new Promise(resolve => {
    rl.question(`${question} [${defaultAnswer === "Y" ? "Y/n" : "y/N"}] `, answer => {
      rl.close();
      resolve(answer.trim().toLowerCase() || defaultAnswer.toLowerCase());
    });
  });
}
```

**Step 3 -- Rewrite the main `initProject` export:**
```javascript
export async function initProject(projectRoot, opts = {}) {
  const { nonInteractive = false, reindex = false } = opts;

  // 1. Scaffold
  const scaffoldResult = scaffoldDocs(projectRoot);

  // 2-3. Detect
  const detection = detectStack(projectRoot);

  // 4. Prompt (if interactive)
  let selectedAgents = detection.agents;
  let selectedRules = filterRelevantRules(detection);
  if (!nonInteractive) {
    printSummary(projectRoot, detection, selectedRules);
    const proceed = await ask("Proceed?", "Y");
    if (proceed === "n") {
      console.log("Aborted. No changes made.");
      return { created: [], skipped: [] };
    }
  }

  // 5. Symlinks
  const symlinkResults = createProjectSymlinks(projectRoot, selectedAgents);

  // 6. Rule templates
  const rulesResult = copyRelevantRules(projectRoot, selectedRules);

  // 7. Manifest
  writeManifest(projectRoot, detection, symlinkResults, rulesResult);

  // 8. Gitignore
  ensureGitignoreEntries(projectRoot, [
    ".agents/skills/", ".claude/skills/",
    ".agents/brief-manifest.json", ".codegraph/"
  ]);

  // 9. Codegraph (non-critical)
  initCodegraph(projectRoot, { reindex });

  return { created: [...scaffoldResult.created, ...symlinkResults.created, ...rulesResult.created], skipped: [...] };
}
```

**Step 4 -- Implement `createProjectSymlinks`:**
Uses `createLink` from `symlink.mjs`. For each detected agent:
- Claude detected → `createLink("~/.agents/brief/skills/brief", join(projectRoot, ".claude/skills/brief"))`
- Always → `createLink("~/.agents/brief/skills/brief", join(projectRoot, ".agents/skills/brief"))` (universal reader dir)

**Step 5 -- Implement `filterRelevantRules`:**
Read `manifest.json` detect patterns. Match against `detection.frameworks` and `detection.languages`. Return only templates whose detect patterns match the project.

**Step 6 -- Implement `writeManifest`:**
Atomic write: write to `.agents/brief-manifest.json.tmp` then rename to `.agents/brief-manifest.json`.

**Step 7 -- Update cli.mjs to pass `--non-interactive`:**
