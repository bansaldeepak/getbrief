# S-011-T1: Relocate Core Skills into Unified Package

**Priority:** P0 | **Status:** in_progress | **Blocked By:** --

## What
Move the three skill directories (`brief`, `sdlc`, `project-memory`) from `~/.agents/custom-skills/` into `~/.agents/brief/skills/brief/` as sub-skills. Create a thin `/sdlc` alias skill. Rewrite all internal path references. Update global `~/.claude/skills/` symlinks to point to new locations.

## Why
Skills currently live in a separate `custom-skills/` directory outside the brief package. This means:
- No single distribution unit (can't install brief and get skills)
- Symlinks into projects point to `custom-skills/` which is not part of the brief package
- Moving to `brief/skills/brief/` creates a unified package: one symlink source, one distribution unit

**Current global symlinks in `~/.claude/skills/`:**

**The sdlc router (`custom-skills/sdlc/SKILL.md`) currently has a route table like:**
```markdown
| `discover` | `~/.agents/custom-skills/sdlc/discover/SKILL.md` | ... |
| `prd` | `~/.agents/custom-skills/sdlc/prd/SKILL.md` | ... |
```
These paths must all change to `~/.agents/brief/skills/brief/<phase>/SKILL.md`.

**The brief router (`custom-skills/brief/SKILL.md`)** may also reference `custom-skills/` paths internally — check and rewrite.

## How

**Step 1 -- Create target directory structure:**
```bash
mkdir -p ~/.agents/brief/skills/brief
mkdir -p ~/.agents/brief/skills/sdlc
```

**Step 2 -- Move sdlc phase skills (with renames):**
```bash
# Direct moves (same name)

cp -r ~/.agents/custom-skills/sdlc/prd ~/.agents/brief/skills/brief/prd
cp -r ~/.agents/custom-skills/sdlc/trd ~/.agents/brief/skills/brief/trd

cp -r ~/.agents/custom-skills/sdlc/retro ~/.agents/brief/skills/brief/retro

cp -r ~/.agents/custom-skills/sdlc/memory-review ~/.agents/brief/skills/brief/memory-review

# Renamed moves
cp -r ~/.agents/custom-skills/sdlc/project-plan ~/.agents/brief/skills/brief/plan
cp -r ~/.agents/custom-skills/sdlc/decision-doc ~/.agents/brief/skills/brief/decision
```

**Step 3 -- Move brief and project-memory:**
```bash
# Move the brief router SKILL.md
cp ~/.agents/custom-skills/brief/SKILL.md ~/.agents/brief/skills/brief/SKILL.md

# Move project-memory
cp -r ~/.agents/custom-skills/project-memory ~/.agents/brief/skills/brief/project-memory
```

**Step 4 -- Rewrite the brief router SKILL.md:**
The main `/brief` router at `~/.agents/brief/skills/brief/SKILL.md` needs its route table updated. All paths referencing `custom-skills/sdlc/` must become `~/.agents/brief/skills/brief/`. Also update the `project-plan` → `plan` and `decision-doc` → `decision` renames.

**Step 5 -- Create thin sdlc alias:**
- File: `~/.agents/brief/skills/sdlc/SKILL.md`
- Content:
```markdown
---
name: sdlc
description: "Lifecycle router — redirects to /brief <phase>. Use /brief directly for all lifecycle commands."
user_invocable: true
argument-hint: "[discover|prd|trd|plan|implement|pr-review|retro|decision|memory-review|bug]"
model: opus
---

# /sdlc — Alias for /brief

This skill is a compatibility alias. The lifecycle router has moved to `/brief`.

**Usage**: Instead of `/sdlc <phase>`, use `/brief <phase>`.

## Routing
```

**Step 6 -- Grep and rewrite all `custom-skills/` references:**

- `project-plan/SKILL.md` → `plan/SKILL.md` (in route tables)

**Step 7 -- Update global `~/.claude/skills/` symlinks:**
